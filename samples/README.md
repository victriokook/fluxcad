# Samples / サンプル

Open these files after starting FluxCAD. They are project-generated examples covered by the repository's MIT license. Save experiments under a new name.

| File | Example |
| --- | --- |
| Sample.FCStd | Plate with rounded edges and four holes / 4穴プレート |
| Primitives-demo.FCStd | Sphere, torus, coil and pipe / 球・トーラス・コイル・パイプ |
| Assembly-demo.FCStd | Basic components and revolute joint / 基本コンポーネントと回転ジョイント |
| Slider-demo.FCStd | Linear motion / スライダージョイント |
| Drawing-demo.FCStd | Linked TechDraw sheet / 関連付いた図面 |
| Sketch-projection-demo.FCStd | Sketch references / スケッチ投影 |
| Sketch-transforms-demo.FCStd | Sketch transformations / スケッチ変形 |

Additional examples cover surfaces, construction geometry, patterns, mirroring, chamfers and inspection. The development-only Drawing-detail demo is omitted from this first package because it embeds separate native hatch resources. The drawing-detail commands themselves remain available through the installed FreeCAD runtime.

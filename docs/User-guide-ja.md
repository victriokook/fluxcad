# FluxCAD — Fusion風のFreeCADワークスペース

Windows向けの初期プロトタイプです。FreeCAD/OpenCASCADEの形状エンジンを利用し、日本語・英語に切り替えられるツールバーと下部のデザイン履歴を追加します。Fusion 360と同一機能の製品ではありません。

## 起動

`Start-FluxCAD.cmd` をダブルクリックします。Program Files内のインストール済みFreeCADを優先して自動検出します。見つからない場合は、`runtime` に置いたポータブル版を使用します。

別のPCではFreeCADをインストールするか、ポータブル版の中身を `runtime` に置いてください。実行ファイルが `runtime/bin/FreeCAD.exe` にある構成です。任意の場所を指定する場合：

```powershell
.\Start-FluxCAD.ps1 -FreeCADPath "C:\path\to\FreeCAD\bin\FreeCAD.exe"
```

FreeCADの「マクロ」メニューから `FluxCAD.FCMacro` を実行することもできます。起動スクリプトは設定・キャッシュを `config` に分離します。

動作例は `Sample.FCStd` を開いてください。80×50×12 mm、R2、直径6 mmの4穴プレートです。

## 表示言語 / Language

右上の「設定 → 表示言語 / Language」で「日本語」または「English」を選択できます。作業を保存し、FluxCADを再起動すると反映します。英語表示では「Settings → Language → 日本語」から戻せます。

リボン、メニュー階層、ブラウザー、各操作パネル、コマンド検索、操作案内、独自のエラー文を切り替えます。FreeCAD標準のメニューとスケッチ編集画面も同じ言語に設定します。言語の選択は保存され、次回以降も引き継ぎます。切り替え時に編集中の文書やプレビューを閉じたり、視点を変更したりしません。

既存の文書名・スケッチ名・ボディ名は翻訳・変更しません。新しく作成する図形の初期名は選択した言語になります。英語の起動案内は `README-en.md` にあります。

配布時は `i18n.py` と `translations_en.py` も本体の `.py` ファイルと一緒に含めてください。個人設定の `config` は配布不要で、言語設定も利用者ごとに保存されます。

## サーフェス・断面

上段の「サーフェス」タブから、FreeCAD標準の面作成を利用できます。

- **作成 → 押し出し／回転**：スケッチや輪郭線全体を選び、長さ・方向または回転軸・角度を指定します。開いた輪郭にも対応し、閉じた輪郭の場合も両端をふさがず面として作成します。
- **作成 → ロフト**：ブラウザーから複数のスケッチ／輪郭をCtrlで順に選びます。標準タスクの左右の一覧で断面を追加・削除し、順番を調整できます。四角形など複数の辺からなる閉じた断面も使えます。
- **作成 → スイープ**：断面用スケッチ／輪郭を選んで実行します。標準タスクの「スイープ経路」を押し、経路の辺を選び、「終了」で経路選択を終えてからOKを押します。断面と経路は別々に指定します。
- **作成 → パッチ**：閉じた境界の辺をCtrlで選ぶか、閉じたスケッチ全体を選択して実行します。選択した辺を境界として面を張ります。平面に収まらない境界にも対応します。標準タスクの境界一覧・支持面・連続性などを調整し、OKで確定します。
- **作成 → 境界サーフェス**：2〜4本の境界曲線から面を作ります。境界の順番・向き・つながりが適切である必要があります。選択は標準パネルで調整できます。
- **作成 → 断面曲線から面**：複数の辺を通る曲面を作ります。Ctrlで断面の順に辺を選んで実行します。各断面は1本の辺です。複数の辺からなる閉じた輪郭を丸ごと断面にするロフトとは操作が異なります。
- **修正 → 面を延長**：面を1つ選び、U−・U＋・V−・V＋の延長率を指定します。U/Vはその面固有の方向です。値は元のパラメーター範囲に対する割合で、ミリ単位の距離ではありません。平面20×10 mmのU＋を10%、V＋を20%にすると22×12 mmになります。「プレビュー」で確認し、OKで確定、キャンセルで元に戻ります。曲面にも使えますが、任意の境界辺を距離指定で延長する操作とは異なります。
- **修正 → オフセット面**：サーフェス全体、または同じボディの面を選び、法線方向の距離をmmで指定します。正の値は法線方向、負の値は反対側です。「プレビュー」で位置と面積を確認できます。ボディ全体や辺の選択ではなく、対象面を選択してください。
- **修正 → 厚み付け**：同じ選択方法で、元の面とオフセット面の間を埋めて新しいボディを作ります。20×10 mmの平面に2 mmの厚みを付けると体積400 mm³になります。正負の値で方向を指定し、曲面にも使えます。結果は1つにつながった立体である必要があります。形状がつぶれる距離や自己交差を解消する機能はありません。ボディの面から新しいボディを作った場合、元ボディは残るので、必要に応じてブラウザーの目のアイコンで非表示にしてください。
- **修正 → 形状を簡略化**：ブラウザーから形状全体を選び、同一平面上の不要な分割線などを取り除きます。「ソリッド → 修正」にもあります。接続済みの面やボディの境界を整理する処理で、離れた面を縫合したり、穴を埋めたりする操作ではありません。元形状は非表示で残り、その変更に追従します。
- **検査 → 断面解析（クリッピング）**：形状を変更せず内部を見る表示機能です。標準パネルでX・Y・Zまたは任意方向の切断平面を有効にし、位置と反転を調整します。元の表示に戻すには平面のチェックを外してください。これは保存する断面形状の作成ではありません。
- **検査 → 断面線を作成**：形状を選び、XY・XZ・YZ平面と位置を指定して曲線を作成します。複数断面では個数・間隔・両側の設定が使えます。断面線は作成時点のスナップショットなので、元形状を変更した場合は再作成してください。

面はブラウザーの「サーフェス」、断面線や読み込んだワイヤーは「曲線」に表示します。目のアイコンで表示を切り替え、右クリックから計測・外観・出力を使えます。パッチ・境界サーフェス・断面曲線から作った面はダブルクリックで再編集できます。辺を追加する場合は標準パネルの **Add Edge** を押してから辺を選択します。キャンセル、確定後のCtrl＋Zにも対応します。スケッチ編集を終えると、編集前のタブに戻ります。

押し出し・回転・ロフト・スイープ・延長の結果も、ブラウザーまたは履歴をダブルクリックして再編集できます。専用の移動可能な画面で、押し出しの長さ・テーパ・対称、回転の角度・軸、ロフトの線織面・閉じる、スイープのフレネ、面の延長率を変更します。プレビュー、キャンセル、Ctrl＋Z／Ctrl＋Yに対応します。参照する輪郭・経路そのものの差し替えはこの再編集画面にはありません。元スケッチを編集するか、新しく作成してください。サーフェス操作では標準タスクの「ソリッド作成」を無効にしています。

オフセット面は「サーフェス」、厚み付けの結果は「ボディ」に表示されます。ブラウザー／履歴のダブルクリックから距離と角の接続（丸める／交差）を再編集できます。操作画面はタイトルバーで移動できます。プレビュー・キャンセル・Ctrl＋Z／Ctrl＋Yに対応し、移動済みの結果の位置も維持します。選択したボディの面は標準の参照オブジェクトで保持し、元ボディの寸法・位置の変更に追従します。

サーフェスと曲線はSTEPに出力できます。サーフェスはSTLにも出力できますが、面の集合なので閉じた立体とは限りません。曲線・点だけのSTL出力はできません。

`Surface-sections-demo.FCStd` に非平面のパッチ、4辺からの面、半円の断面を通る曲面、Z=1・2・3 mmの断面線を収録しています。`Surface-modeling-demo.FCStd` は円の押し出し、半回転、四角形同士のロフト、スイープ、平面の延長の例です。`Surface-finishing-demo.FCStd` は負方向のオフセット面、移動後に厚さを変更した板、円筒面の内向き厚み付け、面とボディの簡略化を収録しています。いずれもFreeCAD標準フィーチャーで、通常のFreeCADでも再計算でき、元の輪郭・経路・面の変更に追従します。サーフェスの縫合は今後の追加対象です。

## 計測・形状検査・尺度・外観

- **計測**：「ソリッド → 検査 → 計測」。辺・面・点を選んで、FreeCAD標準の計測パネルを開きます。Ctrlで2つの頂点を選ぶと距離を測れます。モードで長さ・角度・面積・半径などを選べます。「保存」で残した計測はブラウザーの「計測」に表示され、ダブルクリックで数値確認、目のアイコンで表示切替、右クリックで削除できます。保存しない計測はパネルを閉じると消えます。
- **外形寸法・体積**：従来の表示は「検査 → 計測（寸法・体積）」にあります。メッシュでは外形寸法と三角形数を表示します。
- **形状を検査**：「検査 → 形状を検査」。ボディを選択し、標準パネルで検査設定を選んで「チェックを実行」。結果に無効なシェイプの数を表示します。検査は形状を修復・変形しません。
- **尺度**：「ソリッド → 修正 → 尺度」。形状を選択して、均一倍率またはXYZ別の倍率を指定し、「適用」または「OK」で作成します。FreeCAD標準の `Part::Scale` を使用し、元形状を履歴に残します。倍率を再編集するには、結果のボディまたは尺度変更の履歴をダブルクリックします。専用画面で変更し、OKで反映、キャンセルで変更せず閉じます。Ctrl＋Zで取り消せます。任意の基準点指定はまだありません。
- **外観**：「ソリッド／メッシュ → 修正 → 外観」。選択した形状の表示方法、透明度、線幅、色などをFreeCAD標準パネルで変更します。形状の寸法は変えません。外観はFCStdに保存され、STLには保存されません。

これらの標準タスクを開いている間は、確定または「閉じる」を押してから別の操作に移ってください。計測・外観の設定はFreeCAD側の標準画面を利用しています。

`Scale-inspection-demo.FCStd` は20×10×5 mmの直方体をXYZ方向に2／3／4倍した40×30×20 mmの例です。保存した20 mmの距離計測と透明度45%の外観を含みます。通常のFreeCADでも再計算できます。

## STL・メッシュの操作

STLを「挿入」または「開く」で読み込むと、ブラウザーの「メッシュ」に元の名前で表示します。画面またはブラウザーでクリックして選択し、Ctrl＋クリックで複数選択できます。目のアイコンで表示・非表示を切り替えます。

- **移動**：「メッシュ → 修正 → 移動」または **M**。左ドラッグで移動し、標準では1 mm間隔にスナップします。同じパネルで配置原点のX・Y・Z座標、または現在位置からの移動量を数値指定できます。数値はスナップせずそのまま適用します。
- **回転**：「メッシュ → 修正 → メッシュの回転」。全体座標のX・Y・Z軸と角度を指定します。基準点は選択全体の中心、原点、任意の座標から選べます。
- **サイズ変更**：「メッシュ → 修正 → メッシュのサイズ変更」、またはブラウザーのメッシュをダブルクリック。倍率またはX・Y・Z外形寸法を指定します。「縦横比を固定」を外すと各方向を個別に変更できます。寸法は全体座標軸に沿った外形寸法です。
- **部品分離**：「メッシュ → 修正 → 部品を分離」。1つのSTL内でつながっていない部分を、独立したメッシュに分けます。プレビューの色と部品一覧を確認して確定します。1つにつながっている部分は分離せず、平面切断を使います。
- **平面切断**：「メッシュ → 修正 → 平面で切断」。XY・YZ・XZ平面と全体座標での切断位置を指定し、両側を別々に残す、負方向だけ、正方向だけ、から選びます。「中央に合わせる」で現在の平面方向の中央に戻します。閉じたメッシュでは「切断面を閉じる」が標準で有効です。中空形状の穴を残して切断面を閉じます。元から開いているメッシュは、切断面を開いたまま切断できます。
- **計測・出力**：「検査」で外形寸法と三角形数を確認し、「出力」で変更後のSTLを書き出します。分離・切断した各結果を選択すると個別に出力できます。編集途中はFCStdでも保存できます。

回転・サイズ変更・部品分離・平面切断は確定前にプレビューし、キャンセルで戻せます。確定後はCtrl＋Zで取り消せます。回転・サイズ変更で複数のメッシュを選んだ場合は共通の基準点でまとめて変更します。部品分離・平面切断は1メッシュずつ行い、元のメッシュを非表示で残して結果を追加します。結果は独立した形状で、元のメッシュの後からの変更には追従しません。

回転・サイズ変更・部品分離は三角形の構成を保ち、平面切断は境界の三角形を分割し、必要に応じて切断面の三角形を追加します。全体をソリッドに変換しません。複雑な交点や不正なメッシュで切断面を閉じられない場合は、元の形状を変更せずエラーを表示します。切断位置を少しずらすか、切断面を閉じない設定で再試行できます。任意角度の切断平面、穴あけ、メッシュ結合、頂点の局所編集、ソリッド変換はまだありません。ソリッド用のフィレットや押し出しはメッシュに直接適用できません。STL自体には単位情報がないため、読み込み後に「検査」で寸法を確認してください。

## 最初のモデル

1. 「長方形」で幅60、奥行40を指定します。
2. 選択した状態で「押し出し」を押し、右側パネルで距離12を指定して「確定」を押します。
3. 「穴」（H）を押し、上面をクリックして面内U=30、V=20、直径8、範囲「貫通」を指定し、「確定」を押します。
4. エッジを選択して「フィレット」で半径を指定します。
5. 「保存」で編集用FCStdを保存します。形状を選択し「出力」でSTEPまたはSTLを書き出します。

「スケッチ」は自由作図画面を開きます。平面を選ぶとスケッチ用リボンと右側のパレットが表示されます。閉じた輪郭を作図し、緑の「スケッチを終了」で編集を閉じてから押し出します。既存スケッチはブラウザーでダブルクリックするか、選択して「選択 → スケッチを編集」から開けます。

「スケッチを作成」「スケッチを編集」「スケッチを終了」の切り替えでは、直前の視点・表示位置・ズームを保持します。編集中に回転やズームを行った場合も、終了時にその状態を維持します。作図面を正面から見たいときは右側パレットの「ビュー正面」、画面全体に収めたいときは「全体表示」を使ってください。

スケッチパレットは、標準の「スケッチ編集・拘束・要素」パネルとブラウザーを避けて自動配置します。タイトルをドラッグすると手動配置になり、標準パネルの上も通ってウィンドウの左右の端まで移動できます。上下はリボンと下段タブの間に収まります。手動で配置した位置は、自動配置や定期更新で戻されません。タイトルのクリックで折りたたみ、右クリックの「自動配置に戻す」でパネルの重なりを避ける配置に戻せます。移動した位置と折りたたみ状態は次回起動やスケッチ編集の再開時にも引き継ぎ、ウィンドウを小さくした場合も画面内に収めます。

パレットは作業画面に重ねて表示し、開閉・移動によって描画領域の大きさを変えないため、原点や図形の位置・ズームを維持します。小さいウィンドウでは空いている場所へ収め、高さが足りない分はパレット内をスクロールできます。

スケッチ編集中に以前描いた線や四角形を選ぶときは、上部の「選択」または右側の「選択（作図を終了）」を押し、線・頂点をクリックします。作図・トリムの操作だけを終了し、スケッチ編集は続けられます。複数の辺は Ctrl＋クリック、寸法の変更は数値をダブルクリックします。編集中に「スケッチを編集」を押しても選択に戻れます。寸法や拘束で固定された図形は、選択できても自由にはドラッグできません。

「スケッチを終了」した後、閉じた領域の内側を左クリックすると、その領域が青く塗られます。Ctrl＋クリックで同じスケッチ内の領域を追加・解除し、「押し出し」または E キーで選んだ領域だけをまとめて押し出せます。通常のクリックは選択を置き換え、空白のクリックは選択を解除します。スケッチ編集中の領域選択や、異なるスケッチの領域を同時に押し出す操作は未対応です。

同じスケッチ内で円と四角などが交差している場合も、交点で分かれた領域の内側をクリックして選択できます。例えば円の中心を四角の上辺が通る図形では、重なった半円部分だけを選んで押し出せます。交差する図形をトリムする必要はありません。

長方形を横切る円弧・スプライン・直線で区切った部分や、長方形の辺に曲線の端点をつないで囲んだ部分も選べます。曲線が長方形の外側に膨らんで囲む部分にも対応します。**スケッチを終了 → 領域の内側をクリック → E** で押し出してください。補助線や、途中で途切れて領域を閉じない線は境界にしません。小さな隙間を自動で閉じる処理や、別々のスケッチ間の領域合成は行いません。

曲線で分かれた領域の押し出しは元スケッチに連動し、保存後も通常のFreeCADで再計算できます。辺の追加・削除や交点の数が変わる変更では、領域を選び直して加工を作り直す必要がある場合があります。

交差領域の押し出しは、XY平面だけでなく縦向き・斜め向きのスケッチでも位置と向きを維持します。既存の立体と重なっている場合は、押し出しパネルで新規ボディ・結合・切り取り・交差を指定できます。

交差しない輪郭では、辺を1本クリックして、その辺が属する領域を押し出す操作も使えます。押し出しパネルの「領域」一覧には各面積が表示され、チェックで対象を追加・解除できます。全てのチェックを外すと「確定」は無効になります。交差する輪郭の辺や別々の領域の辺を同時に選んだ場合は、領域の内側から選び直してください。内側の輪郭は穴として維持され、穴の内側は領域として選択しません。手前の立体に隠れている領域も選択しません。

複数領域の押し出しでは、元スケッチにリンクする標準SubShapeBinderで対象領域を分離します。交差する輪郭にはFreeCAD同梱のBooleanFragmentsも使用します。選択していない輪郭は表示したままなので続けて別の輪郭を選べます。交点の数が変わるなど、領域の構成自体が変わる編集では押し出し対象の再確認が必要です。以前のバージョンで作った一括押し出しは自動では分離されません。

「新規ボディ」では、辺を共有する隣り合った領域は継ぎ目を除いた1つのボディに、離れた領域は別々のボディ・履歴にします。作成時は共通の距離と方向を使い、作成後は各ボディの押し出し長さを独立して変更できます。元スケッチの寸法変更にはそれぞれ追従します。「結合」「切り取り」「交差」では、全ての選択領域を1つの対象ボディへまとめて適用し、履歴から長さを変更すると選択領域全体へ反映します。確定は1回のUndoで全体を取り消せます。キャンセルすると元の領域選択に戻ります。

## 押し出し

領域またはスケッチを選択して E キーを押すと、右側に押し出しパネルが開きます。距離・方向・操作を変えると、確定後の形状を半透明でプレビューします。切り取りでは、削った後に残る形状を表示します。プレビュー中も中ボタンによる視点移動、Shift＋中ボタンによる回転、ホイールによるズームが使えます。

| 操作 | 作成する形状 |
| --- | --- |
| 新規ボディ | 独立した押し出し形状 |
| 結合 | 選択した対象ボディに押し出しを加えた形状 |
| 切り取り | 対象ボディから押し出し部分を削った形状 |
| 交差 | 対象ボディと押し出しが重なる部分だけ |

結合・切り取り・交差では「対象ボディ」を選びます。対象は1つです。重なりがなく加工できない場合や、結合しても離れた立体になる場合は、パネルに理由を表示します。条件を変更して有効な形状になると「確定」を押せます。

方向は「片側」「逆方向」「対称」「両側」です。「対称」の全長12 mmはスケッチ面から両方向へ6 mmずつ、「両側」ではそれぞれの距離を別々に指定します。方向はスケッチ面を基準にするため、傾いた面からの切り取りもできます。

**開始オフセット** で、スケッチを動かさずに押し出しの開始面をずらせます。0 mmはスケッチ面、正の値は「片側」の方向、負の値はその反対方向です。例えばXYスケッチで開始オフセット5 mm・距離10 mm・片側なら、Z=5～15 mmの形状を作ります。入力は−100000～100000 mm、0.001 mm単位です。

方向を逆にしても開始面は変わりません。同じ開始オフセット5 mm・距離10 mmで「逆方向」ならZ=−5～5 mm、「対称」ならZ=0～10 mmになります。「両側」の2つの距離と勾配も、この移動した開始面を基準にします。オフセット分の空間は押し出しに含めず、元スケッチの位置・寸法は保持します。傾いたスケッチでは、その面に垂直な方向にずらします。

距離・面まで・貫通の各範囲で開始オフセットを使えます。「面まで」は移動した開始面から終点まで押し出し、「貫通」の片側・逆方向はその開始面から指定方向だけを切り取ります。開始面の両側を切り取りたい場合は「両方向」を選びます。オフセット後の終点を越える開始位置や、指定方向に対象ボディがない場合は確定できません。

オフセット付きで作成した押し出しは、履歴または最終ボディのダブルクリックで再編集できます。開始オフセットを0に戻すこともでき、スケッチの変更への追従・保存と再読込・Ctrl＋Zに対応します。オフセットのない旧版の範囲・勾配付き押し出しは0 mmとして読み込みます。従来の通常押し出しの履歴編集は長さ指定のままです。

「範囲」は次の3種類から選べます。

- **距離**：数値で押し出し長さを指定します。従来どおり4種類の方向を使えます。
- **面まで（平面）**：終点の基準にするソリッドの平らな面、または表示中の構築平面をクリックします。「終点の面を選択」で選び直せます。片側・逆方向に対応し、傾いた平面の場合は先端もその傾斜に合わせます。小さい面でも、その平面を輪郭の外側まで延長して終点にします。曲面、押し出し方向と平行な面、オフセット後の終点が開始位置の輪郭を横切る場合は対象外です。
- **貫通**：操作は「切り取り」になり、選んだ対象ボディの厚さに合わせて切り抜きます。初期状態は「両方向」で、開始面の両側を貫通します。「片側」「逆方向」にすると、その側だけを加工します。距離の入力は不要です。

範囲「面まで」では **終点オフセット** を指定できます。0 mmは選んだ面まで、＋2 mmは面を2 mm越えて延長、−2 mmは2 mm手前で停止します。距離は押し出し方向に測り、「逆方向」でも正の値はその方向へ延長します。斜めの面は、傾きを保ったまま押し出し方向へ平行移動します。斜めの面に垂直なすき間の距離とは異なります。

開始オフセットと併用できます。例えばXYスケッチからZ=20 mmの平面へ片側に押し出すとき、開始オフセット5 mm・終点オフセット−2 mmならZ=5～18 mm、終点オフセット＋2 mmならZ=5～22 mmです。入力は−100000～100000 mm、0.001 mm単位です。参照面の形状・配置は変更せず、参照面が動いたときも指定したオフセットを保って再計算します。

終点オフセットは新規ボディ・結合・切り取り・交差、履歴からの再編集、保存と再読込、Undoに対応します。旧版の押し出しは終点オフセット0 mmとして読み込みます。距離・貫通では使用せず、その範囲で確定すると終点オフセットは0になります。オフセット後の終点が開始位置と一致する・手前にある・輪郭を横切る場合は確定できません。勾配角と組み合わせて使用できます。

範囲「距離」「面まで」「貫通」で **勾配角** を指定できます。0°は垂直、正の角度は先端を広げ、負の角度は先端を狭めます。例えば10×8 mmの長方形を5 mm押し出して10°にすると、先端は各辺で約0.882 mmずつ外へ広がります。「距離」の「対称」は開始面（オフセット0ではスケッチ面）を基準に両側へ同じ勾配を付け、「両側」は「反対側の勾配角」で別の角度を指定します。逆方向でも正負の意味は同じです。

「面まで」は勾配を付けた先端を指定した平面で切りそろえます。斜めの平面、開始オフセット、終点オフセットとの併用に対応します。「貫通」は対象ボディの厚みに合わせて勾配付きで切り取り、「両方向」は開始面からそれぞれの方向へ同じ勾配を付けます。範囲を切り替えても勾配角は保持されます。

勾配は新規ボディ・結合・切り取り・交差に対応します（貫通は切り取りのみ）。穴の内壁にも勾配が付き、正の角度では外形が広がり、穴は狭まります。角度の入力範囲は−89°～89°ですが、輪郭や穴がつぶれる・交差する・辺の数が変わる形状は作成できません。終点まで輪郭を保てない場合や、勾配と終点面の傾きによって閉じた立体にならない場合も確定できません。距離や角度を小さくするか、終点面を調整してください。

勾配付きで作成した押し出しは、履歴または最終ボディをダブルクリックして角度・距離を再編集できます。0°へ戻すこともでき、スケッチ寸法の変更、保存と再読込、Ctrl＋Zに対応します。隣り合う選択領域は境界を結合してから勾配を付けます。

「面まで」は参照面の移動に、「貫通」は対象ボディの厚さや位置の変更に追従します。どちらも同じスケッチの複数領域に対応し、新規ボディでは離れた領域を別のボディとして作成します。スケッチの寸法変更にも追従しますが、輪郭や参照面を削除するような変更では、参照の選び直しや作り直しが必要になる場合があります。

これらの範囲で作成した押し出しは、履歴をダブルクリックして同じパネルで再編集できます。最後の加工がその押し出しの場合は、ブラウザーのボディをダブルクリック、または右クリックの「押し出しを編集…」でも開けます。範囲・方向・終点の面・距離・開始と終点のオフセットを変更でき、移動済みボディの配置は保持します。再編集時は元の領域、操作（新規・結合・切り取り・交差）、対象ボディは固定です。以前の距離指定の押し出しは、従来どおり履歴から長さを変更します。

「面まで」「貫通」「勾配付き」「開始オフセット付き」で作成した押し出しの再計算には `model_extents.py`、`model_taper.py` と依存モジュールが必要です。保存したFCStdはFluxCADを起動してから開いてください。完成形状の受け渡しにはSTEPやSTLも使えます。

「確定」で履歴に追加し、Ctrl＋Zで操作全体を取り消せます。「キャンセル」または Esc は、プレビューを消して元の表示と選択に戻します。パネルの開閉・確定による自動ズームはありません。別のコマンドやブラウザーでの選択へ移った場合も、未確定の押し出しは取り消します。

## ボディを分割

「ソリッド → 修正 → ボディを分割」で、1つのソリッドを平面の両側の2つのボディに分けます。ケースの上下分割や、別々に出力する部品の作成に使えます。

1. 分割するボディを選び、「ボディを分割」を開きます。パネルの「対象ボディ」からも選択できます。
2. 「切断平面」をXY・XZ・YZから選び、「オフセット」をmmで指定します。主要平面を選ぶと、最初はボディの外接箱の中央に合わせます。
3. 任意の平らな面を使う場合は「選択した面・構築平面」に切り替え、「面・構築平面を選択」を押して3D画面の面をクリックします。ボディと構築平面を先に選択してから開くこともできます。選択した面は、その輪郭の大きさに関係なくボディ全体を横切る平面として扱います。
4. オフセットは平面の法線方向が正、反対方向が負です。例えば直方体の上面を選び、負の値を入れると内側に切断位置を移せます。「ボディの中央に合わせる」でも位置を設定できます。
5. 青とオレンジの結果を確認して「確定」を押します。「切断平面を表示」で補助表示を切り替えられます。

ブラウザーには分割後の2つのボディが並び、個別の選択・移動・回転・追加加工・STEP/STL出力ができます。元のボディは非表示で履歴に残ります。下部の「ボディを分割」をダブルクリックすると、共通の切断平面と位置を再編集できます。分割直後のボディをブラウザーでダブルクリック、または右クリックの「分割位置を編集…」から開くこともできます。分割したボディの配置・色・表示状態は再編集でも保持します。削除した分割ボディは再編集しても自動復元しません。

元ボディの寸法や参照平面を変更すると結果も再計算します。切断位置の再編集で後の加工を更新できない場合は、変更全体を取り消します。確定は1回のCtrl＋Zで取り消せます。キャンセル・Esc・別コマンド・別文書への切り替えでは、仮表示を消して元の表示に戻します。パネルはタイトルをドラッグして端まで移動でき、折りたたみもできます。視点・ズームは自動変更しません。

今回は、1つにつながったソリッドを、両側に1つずつのソリッドが残る平面で分割する範囲に対応します。接するだけ・交差しない平面や、3個以上に分かれる切断は確定できません。曲面・スケッチの輪郭による分割、メッシュへの適用は未対応です。参照面の番号が変わる大きな形状変更では面を選び直す必要があります。再計算・再編集には独自の `model_split.py` が必要なため、FCStdはFluxCADを起動してから開いてください。完成形状を受け渡す場合はSTEP/STLを使用できます。

## フィレットと面取り

「ソリッド → 修正 → フィレット」（3DビューでFキー）で角を丸め、「面取り」で角を斜めに落とします。どちらも専用パネルで加工する辺と寸法を指定し、結果をプレビューしてから確定できます。辺を選択してから開くと、選択した辺でプレビューを開始します。ボディだけを選ぶ、または何も選ばずに開いてから、画面上で辺を選ぶこともできます。

「辺を選択」を押すと加工前の形状に戻り、クリックで1辺を選択、Ctrl＋クリックで追加・解除します。同じボディの辺を選び、終わったら「選択を終了してプレビュー」を押してください。パネル内の辺のチェックでも追加・解除できます。表示する辺番号と長さは加工前の形状を基準にし、選択中の辺はオレンジ色で表示します。見えない裏側の辺は視点を回して選ぶか、一覧から指定してください。

フィレットは「半径」をmmで入力します。面取りは「面取りの種類」で「等距離」または「2つの距離」を選びます。「等距離」は両側に同じ「距離」を取り、「2つの距離」は例えば「距離1＝1 mm」「距離2＝3 mm」のように、辺に隣接する2つの面に沿った距離を個別に指定します。「距離1と2を入れ替え」で削る向きを変更できます。複数の辺には同じ寸法を適用し、入れ替えも一括で行います。距離1・2に対応する面は辺ごとに異なる場合があるため、プレビューで向きを確認してください。面取りの数値は小数点以下6桁まで入力できます。

数値やチェックを変更するとプレビューが更新されます。寸法が大きすぎる・選択した辺では加工できない・選択が空の場合は確定できず、理由を表示します。元の形状は確定まで変更しません。キャンセルまたはEscで元の表示・選択に戻り、確定後はCtrl＋Zで操作全体を戻せます。

履歴をダブルクリックすると、加工する辺と寸法・面取りの種類を再編集できます。最終加工がフィレット・面取りのボディは、ブラウザーのダブルクリックまたは右クリック「辺と寸法を編集…」でも開けます。移動・回転した結果も位置を保ち、以前に作った一定寸法のフィレットや、全辺で同じ寸法を使う標準FreeCADの等距離・2距離面取りにも対応します。元ボディの寸法変更には追従しますが、パネルを開いている間に元形状を変更した場合は、辺を選び直してください。後工程を更新できない変更は取り消します。

パネルのタイトルをドラッグすると左端を含めて移動でき、タイトルまたは矢印のクリックで折りたたみます。位置は次回も保持し、穴パネルとは別に記憶します。中ボタンの平行移動、Shift＋中ボタンの回転、ビューキューブの操作は継続できます。操作中に視点やズームを自動変更しません。

対象は1つにつながったソリッドです。一定半径のフィレットと等距離・2距離の面取りに対応し、可変半径、辺ごとに異なる寸法、角度指定の面取り、接線つながりの自動選択、メッシュへの直接適用は未対応です。標準FreeCADのフィーチャーとして保存するため、FluxCADがない環境でも再計算できます。辺の数・構成が変わる大幅な元形状の変更では、加工する辺の再確認が必要です。

`Chamfer-distances-demo.FCStd` は、青の等距離2 mm、緑の1×5 mm、紫の5×1 mmを比較するサンプルです。各ボディをダブルクリックして寸法を変更できます。

## 面を選択して穴あけ

「ソリッド → 作成 → 穴」またはHキーを押し、ソリッドの平らな面をクリックします。面を先に選択してからHを押しても開始できます。選んだ面に垂直に、ボディの内側へ穴を開けます。側面や傾いた平面にも対応します。

クリックした位置を穴の中心にし、黄色い円とU・Vの目印を表示します。プレビュー中に同じ面をクリックすると位置を変更できます。「面を選び直す」で別の面を指定します。穴を再編集している場合は、元のボディの面から選び直します。クリックは標準で1 mm間隔にスナップし、間隔の変更やスナップの解除もできます。

「面内U」「面内V」で正確な位置を指定します。基準点は、加工元ボディの配置原点を選択面に垂直投影した点です。U・Vは画面の横・縦や全体座標のX・Yと一致するとは限らないので、穴の位置に表示されるU・Vの向きを確認してください。数値入力にはスナップをかけません。「直径」と「貫通／深さを指定」を設定し、結果をプレビューしてから確定します。深さ指定は選択面からの距離で、底は平らです。

「穴の種類」で通常の穴・ザグリ穴・皿穴・ねじ穴を切り替えます。

- **ザグリ穴**：小さい穴の「直径」に加え、入口の「ザグリ径」と「ザグリ深さ」を指定します。例えば直径6 mm、ザグリ径12 mm、ザグリ深さ4 mmでは、面から4 mmまでが直径12 mmの段付き穴になります。
- **皿穴**：小さい穴の「直径」、入口の「皿穴径」、「皿角度」を指定します。角度は円すいの全角で、標準は90°です。例えば直径6 mm、皿穴径12 mm、90°では皿穴部分の深さが3 mmになります。計算した深さもパネルに表示します。

どちらも「貫通」と「深さを指定」に対応します。「全体の深さ」は選択面から穴の底までの距離で、ザグリ・皿穴部分を含みます。入口の径は小さい穴の直径より大きくし、深さ指定の場合は全体の深さをザグリ・皿穴部分より大きくしてください。貫通の場合、ザグリ・皿穴部分が薄いボディを突き抜ける設定も可能なので、プレビューで確認してください。黄色い2本の円が小さい穴と入口の径を示します。

**ねじ穴**では「ねじ規格」でメートル並目・細目を選び、「呼び径 × ピッチ」（例：M6 × 1.0）、右ねじ・左ねじを指定します。呼び径・ピッチの組合せと下穴径は、インストールしたFreeCADの規格一覧を使用します。公差等級は6Hです。穴は貫通または深さ指定にでき、ねじ部分は「穴と同じ深さ」または個別の「ねじ深さ」を選べます。個別のねじ深さは穴の深さ以下にしてください。

- **軽量表示（初期設定）**：下穴の円筒形状と、呼び径・ピッチ・方向・ねじ深さの情報を保存します。ねじ山の形状はありません。
- **ねじ山を実体化**：FreeCADの穴機能で実際のらせん状のねじ山を生成します。STL・STEPにもねじ山を出力できます。例えば穴深さ8 mm、ねじ深さ4 mmでは、入口側4 mmをねじ加工します。計算量を抑えるため、実体化する深さは1〜50ピッチに制限しています。長い穴はねじ部分だけ短くするか、軽量表示を使用してください。

まず「H → 面をクリック → 穴の種類：ねじ穴 → M6 × 1.0」の順で試せます。ねじ山を見たい場合は「ねじ山を実体化」を有効にして確定します。外ねじ、インチ・管用ねじ、ねじ穴とザグリ・皿穴の同時指定、実体化時の任意クリアランスは未対応です。

穴の操作パネルは、上部の「穴／穴を編集」のタイトルをドラッグして移動できます。左端にも配置でき、移動先を次回以降も記憶します。タイトルまたは左の矢印をクリックすると、タイトルだけに折りたたみます。折りたたみ中も穴のプレビューと位置のクリック指定は続けられ、展開すると入力値を保ったまま操作に戻れます。タイトルを右クリックして「右側の初期位置に戻す」を選ぶと配置を戻せます。ウィンドウを小さくした場合は、操作パネルが画面内に収まるよう調整します。

確定するまで形状は追加されず、キャンセルまたはEscで元の表示と選択に戻ります。確定後はCtrl＋Zで操作全体を取り消せます。履歴の「穴」をダブルクリックすると位置・直径・深さを再編集でき、最後の加工が穴の場合はブラウザーのボディをダブルクリック、または右クリックの「穴を編集…」でも開けます。移動・回転したボディの穴も、その配置を保って再編集します。

加工元の形状・配置との依存関係を保持し、貫通穴はボディの厚さ変更にも追従します。編集中に加工元を変更した場合は、古いプレビューの確定を無効にし、面の選び直しを求めます。参照面を削除するような形状変更では再指定が必要になる場合があります。

履歴から再編集して、通常の穴・ザグリ穴・皿穴・ねじ穴を相互に切り替えることもできます。以前の穴パネルで作成した通常の穴も、そのまま開いて編集できます。種類や追加寸法の変更は保存・再読み込み、元に戻す／やり直すに対応します。

対象はソリッドの平面です。曲面、STLなどのメッシュは未対応です。旧版の「貫通穴（Z方向）」は既存の方式を保持し、新しい穴パネルへの自動変換は行いません。新しい穴はFCStdに保存でき、再計算・再編集にはFluxCADの`model_hole.py`、`model_thread.py`と依存モジュールが必要です。FluxCADを起動してからファイルを開いてください。完成形状だけを渡す場合はSTEPやSTLを出力できます。

## 回転とパターン

「回転」はスケッチの断面を軸のまわりに回して、新しいボディを作ります。スケッチ編集を終了し、閉じた領域またはスケッチを選択して「作成 → 回転」を押してください。右側パネルで軸・角度・方向・軸の通過点を指定し、プレビューを確認して「確定」を押します。交差した輪郭の一部も、押し出しと同じように領域を選択できます。

回転・円形パターンの「軸の指定」は、次の3通りから選べます。

- **全体座標の軸**：X・Y・Z方向と「軸の通過点」を指定します。原点以外を通る軸にもできます。
- **辺・円筒面・構築軸**：3D画面で直線の辺、スケッチの直線、円筒の側面、または構築軸をクリックします。構築軸はブラウザーの「構築」からも選べます。斜めの辺や穴の内壁も使用できます。「参照軸」のボタンで選び直します。選択中は元形状を表示し、クリック後にプレビューへ戻ります。
- **方向を数値で指定**：軸の方向X・Y・Zと通過点X・Y・Zを入力します。例えば方向(1,1,0)はXY面内で45°の軸です。方向は自動的に正規化し、(0,0,0)は使用できません。通過点は全体座標のmmで、小数6桁まで入力できます。

緑の矢印で軸の向きを確認し、「正方向／逆方向」を選びます。角度は0より大きく360°以下です。例えばXY平面の原点から幅4 mm・高さ6 mmの長方形を描き、Y軸まわりに360°回すと半径4 mm・長さ6 mmの円柱になり、断面を軸から離すとリングになります。

選択した辺・円筒面・構築軸は参照元に追従し、参照形状や既存コンテナーの配置を変更すると再計算します。全体座標・数値で指定した軸は固定です。参照の辺・面がなくなった場合や大きな形状変更で番号が変わった場合は、履歴編集から軸を選び直してください。パネルを開いている間に参照元が変わった場合も再選択が必要です。円弧・平面・メッシュは軸に指定できません。円すいの場合は、先に「円柱・円すいの中心軸」を作って選択してください。この操作の結果や後の加工を参照する循環指定もできません。

辺・円筒面を参照した軸の再計算には `model_axis.py` と依存モジュールが必要です。保存したFCStdは **FluxCADを起動してから開いてください**。全体座標・数値で指定した軸は標準FreeCADのプロパティだけで再計算できます。

ボディを選択して「作成 → パターン」から「矩形状パターン」または「円形状パターン」を実行すると、同じ形状を規則的に配置できます。こちらも数値を変えるとプレビューが更新され、「確定」まで文書に形状を追加しません。

| 機能 | 指定内容 |
| --- | --- |
| 矩形状パターン | 全体座標のX・Y・Zから1軸または異なる2軸を選択。方向ごとの個数、間隔または配置範囲の全長。負の距離で逆向きに配置 |
| 円形パターン | 回転軸、軸の通過点、個数、配置角度、方向。コピーの向きも軸に沿って回転 |

矩形状パターンの初期状態は1方向です。「方向2 → 使う」で2方向の格子状配置になります。例えば方向1をX・3個・間隔10 mm、方向2をY・4個・間隔15 mmにすると、元の位置を含む3×4＝12か所に配置します。個数は方向1が2～200、方向2も使用時は2～200で、積が200以内になるよう指定してください。XZ・YZ方向にも並べられます。

「距離の指定 → 間隔」は隣り合う配置原点どうしの距離です。「全長」は最初から最後の配置原点までの距離で、部品自体の幅は含みません。全長30 mm・4個なら0・10・20・30 mm、全長30 mm・6個なら0・6・12・18・24・30 mmに配置します。全長指定で個数を変えても両端の位置を保ちます。距離の指定方法を切り替えると、その時点の個数から距離を換算します。

方向2の「使わない」で1方向に戻せます。パネル内でオン・オフする間は方向2の入力値を保持します。以前の1方向パターンは「間隔」として読み込み、履歴から2方向へ変更できます。保存と再読込・Undo/Redoに対応し、標準FreeCADの配列と数式を使うため、FluxCADを読み込まずに元ボディの寸法・個数を変更しても再計算できます。

円形パターンの個数は元の位置を含めて2～200個です。360°・4個なら0°・90°・180°・270°、180°・3個なら0°・90°・180°です。

パターンはコピーを結合せず、全体をまとめて1つの履歴・ブラウザー項目として扱います。元のボディは履歴に残し、元形状の寸法変更は全コピーへ反映します。Mキーでパターン全体を移動できます。個々のコピーを独立して動かす操作や、穴・フィレットだけを複製するフィーチャーパターン、矩形状パターンの3方向配置・任意の斜め軸は未対応です。

回転・パターンの履歴をダブルクリックすると、角度・軸・間隔・個数などを再編集できます。確定した操作全体はCtrl＋Zで戻せます。キャンセルまたはEscでは、元の表示と選択に戻し、履歴を増やしません。作成・編集によって視点やズームを自動変更しません。

回転・パターン・ミラー・シェル・ロフト・スイープ・オフセット平面の操作パネルは、タイトルをドラッグして左端まで移動でき、タイトルや矢印で折りたためます。位置は次回も記憶し、タイトルの右クリックで右側の初期位置へ戻せます。

## ボディの回転・コピー

立体を選択して「ソリッド → 修正 → 移動 / コピー（回転）…」を開きます。修正グループの回転矢印アイコンからも開けます。複数の立体はCtrl＋クリックで選択してください。

- 「回転」：全体座標のX・Y・Z軸と角度を指定します。角度は負の値と小数に対応し、−90°・＋90°・180°ボタンも使えます。
- 「回転中心」：選択した全ボディの外接ボックスの中心、原点、任意のX・Y・Z座標から選べます。プレビュー中の色付き十字が回転中心です。複数ボディは共通の中心・軸で回り、互いの位置関係を保ちます。
- 「移動」：全体座標のX・Y・Z方向の移動量をmmで指定します。数値はスナップせず、そのまま適用します。
- 「コピーを作成」：元のボディを残し、指定した配置へ独立したボディを作ります。コピーは作成時点の形状であり、元ボディの後の寸法変更には追従しません。移動量・角度が0でも同じ位置にコピーできます。

プレビューを確認して「確定」を押してください。キャンセルまたはEscでは元の表示・選択に戻り、Ctrl＋Zで複数ボディの操作全体を取り消せます。通常の回転・移動では元の押し出しなどの寸法編集を維持します。コピーはブラウザーで個別に選択・移動できます。保存後は標準FreeCADでも開けます。

この操作では自動ズームを行いません。スケッチ編集を終了してから使用してください。回転は数値指定に対応し、回転ハンドルのドラッグや任意のエッジを回転軸に選ぶ操作は未対応です。従来のドラッグ移動・1 mmスナップ・配置先座標の指定はMキーから使えます。

## 面を使った位置合わせ

「ソリッド → 修正 → 位置合わせ…」を開き、移動するボディの平らな面、合わせ先の平らな面の順にクリックします。面はCtrlを押さずに選べます。先に2つの面をCtrl＋クリックで選択してからコマンドを開く場合は、先に選んだ面のボディが移動します。

初期状態では、2つの面の中心を一致させ、面が向かい合うようにボディを回転・移動します。「面の中心」は面積の重心です。合わせ先のボディは動かしません。原点軸に対して斜めの平面や、構築したオフセット平面を合わせ先にすることもできます。

- 「平面のみを合わせる」：移動する面の中心を保って向きを変え、合わせ先の面に垂直な方向だけ移動します。合わせ先の面に沿う方向の位置は保持します。
- 「すき間」：mmで距離を指定します。0で面が同じ平面上になり、正の値は合わせ先の面の外向き、負の値は内向きへ配置します。
- 「反転」：面を向かい合わせる／同じ向きにそろえるを切り替えます。「面内の回転」は合わせ先の面の法線を軸に回転し、任意の角度入力と＋90°ボタンが使えます。
- 「面を入れ替え」：動かす側と合わせ先を交換します。選択欄を押すと、その面だけ選び直せます。
- 「コピーを作成」：元のボディを残し、独立したコピーを合わせ先へ配置します。

プレビューを確認して「確定」を押します。キャンセルまたはEscで元の表示と選択に戻り、Ctrl＋Zで配置全体を戻せます。視点・ズームを自動変更しません。数値や面を確定するまで、ボディの配置や形状は変更しません。

円筒を合わせる場合は、移動するボディの円筒の側面、合わせ先の円筒の側面の順にクリックします。「位置合わせ — 同軸」に自動で切り替わります。円柱の端の平らな面ではなく、曲がった側面を選択してください。穴の内壁や、一部だけが残っている円筒面にも対応します。半径が違う面どうしでも中心軸を一致させられ、直径は変更しません。

- 「軸方向の中央を合わせる」：選択した2面の軸方向の範囲の中央を一致させます。部品全体の中心ではありません。
- 「軸方向の位置を保持」：合わせ先の軸に沿う現在位置を保ちながら、中心軸を一致させます。その後、指定したオフセットを加えます。
- 「軸方向オフセット」：軸に沿ってmm単位でずらします。正方向は合わせ先の緑の「＋」矢印です。面の作り方によって向きが異なるため、全体座標の＋Z方向とは限りません。数値は小数点以下6桁まで入力でき、グリッドには丸めません。
- 「軸まわりの回転」：合わせ先の軸を中心に任意角度で回します。「反転」で軸の向きを逆にできます。「面を入れ替え」「コピーを作成」も使用できます。

平面と円筒面を混ぜて選択した場合、円すい・球面などを選択した場合、同じボディどうしの場合は確定できません。円形の辺・頂点による位置合わせ、直径の自動変更、干渉・はめあいの判定は未対応です。配置がすでに一致している場合は変更せず、「コピーを作成」を選ぶと同じ位置に独立コピーを作れます。

位置合わせパネルは見出しをドラッグして左右の端まで移動でき、クリックで折りたたみます。位置は次回も保持します。作業中もマウスやビューキューブで視点を変えられます。

位置合わせは配置を変更する操作で、ジョイントや継続的な拘束は作りません。後から合わせ先の寸法や位置を変更しても自動追従しません。通常の移動では元の押し出しなどの寸法編集を維持し、コピーは作成時点の形状になります。保存後も標準FreeCADで配置を維持できます。

## ロフトとスイープ

「ロフト」は、離れた位置にある2つ以上の断面スケッチを順につないで、新しいボディを作ります。ブラウザーのスケッチをつなぐ順番にCtrl＋クリックし、「作成 → ロフト」を押してください。パネルで断面を追加・削除でき、↑↓で順序を変更できます。何も選択せずにコマンドを開き、パネルで順番に追加することもできます。

断面は、それぞれ1つの閉じた輪郭を持つ別々のスケッチです。「滑らかにつなぐ」と「断面間を直線でつなぐ」を選べます。例えばZ=0に半径2 mm、Z=20に半径4 mmの円形スケッチを置くと、先が広がる円すい台になります。断面スケッチは「構築 → オフセット平面」で異なる高さの平面を作り、その平面を選択して作成できます。既存スケッチの位置は、FreeCAD標準UIのPlacementでも設定できます。

「スイープ」は、1つの断面を別のスケッチの経路に沿って伸ばします。閉じた断面スケッチ、経路スケッチの順にCtrl＋クリックして「作成 → スイープ」を押します。パネルの「断面」「経路」でも選び直せます。経路は1本につながった直線・円弧などで、閉じた経路にも対応しています。断面は経路の端（閉じた経路なら始点）に、経路と直角になるよう配置してください。

スイープの「断面の向き」は「ねじれを抑える」または「経路の曲がりに追従」を選びます。経路の角では「角を合わせる」「丸く接続」などを選べます。断面が大きすぎる、経路が急に折れ曲がるなどの理由で立体を作れない場合は、理由を表示して確定を無効にします。

どちらもプレビューを見て確定でき、Ctrl＋Zで操作全体を戻せます。履歴のダブルクリックで断面・経路・つなぎ方を再編集できます。元スケッチの寸法や配置の変更にも追従し、作成済みの立体を移動してから再編集しても移動位置を維持します。パネル操作による自動ズームはありません。

現在はスケッチ全体を断面・経路として使用します。断面内の穴、複数輪郭・交差領域の部分選択、ロフトのガイドレール、スイープの途中で断面寸法を変える操作は未対応です。新規ボディとして作成し、必要に応じて後から結合・切り取りを使います。

## ミラーとシェル

ボディを1つ選択して「作成 → ミラー」を押すと、対称なボディを作成できます。ミラー平面は全体座標のXY・XZ・YZから選び、「面の位置」で原点からの位置をmmで指定します。例えばYZ平面・位置10 mmなら、X=10 mmの平面を挟んで反転します。元のボディは残り、ミラー側を別のボディとして選択・移動できます。元形状の寸法変更には追従します。

任意の斜面や構築平面を使う場合は、ミラー平面を **「選択した面・構築平面」** に切り替え、モデルの平らな面をクリックします。構築平面はブラウザーの「構築」からも選べます。ボディを選び、Ctrlで基準面を追加してから開始すると、その面を入力済みにします。ボディの面を1つだけ選んで開始した場合は、そのボディをその面に対してミラーします。

**「面からのオフセット」** は、選んだ面から垂直に測った距離です。0 mmは面上、正の値はオレンジの矢印方向、負の値は反対側です。例えばXY方向の上面がZ=10 mmなら、＋2 mmでZ=12 mmを対称面にします。鏡像の位置は対称面の移動量の2倍だけ変わります。数値は小数点以下6桁まで指定でき、グリッドには丸めません。オレンジの枠は基準面の向きを示す補助表示で、枠や元の面より大きなボディも無限の平面に対して反転します。

選択した面の移動・回転や構築平面の角度・距離を変更すると、ミラーしたボディも追従します。構築平面の表示サイズを変えても結果は動きません。「基準面」ボタンから面を選び直せます。基準面のボディはミラーの対象にはならず、元のボディとミラー結果も結合せずに残します。必要なら後から「結合」を使います。

ミラーしたボディをブラウザーでダブルクリック、右クリックの「ミラーの基準面を編集…」、または履歴のダブルクリックで再編集できます。基準面・オフセットを変更しても、ミラー結果に後から加えた移動・回転は保持します。後続の加工を壊す変更は取り消します。編集パネルを開いたまま基準面が変わったときは、「基準面」から選び直してください。

基準は平面に限ります。曲面・辺・メッシュ、このミラー自身や後続の加工は選択できません。参照面の削除や面番号が変わる大きな変更では、基準面を選び直してください。選択した面に追従するミラーは `model_mirror.py` を使用するため、保存したFCStdは **FluxCADを起動してから開いてください**。従来のXY・XZ・YZ指定は標準FreeCADのミラーのままです。`Mirror-plane-demo.FCStd` に、20°傾けた構築平面に追従するブラケットの例があります。

立体を中空にするには、開けたい面をクリックして「修正 → シェル（中空化）」を押します。同じ立体の複数の面はCtrl＋クリックで選べます。パネルの「開ける面」でもチェックを変更でき、ボディ全体を選んでから開ける面を指定することもできます。

厚さは正のmm値で指定します。「内側」は元の外形を保ち、内側へ壁厚を取ります。「外側」は元形状を空洞として、その外側へ壁を作ります。角の接続は鋭角です。厚さが大きすぎるなど、形状を作れない場合は元のボディを保って理由を表示します。

どちらも数値変更でプレビューが更新され、「確定」で履歴に追加します。Ctrl＋Zで操作全体を取り消せ、履歴のダブルクリックで平面や厚さなどを編集できます。キャンセルでは元の表示・選択に戻り、視点・ズームは変わりません。標準FreeCADのミラー・厚みフィーチャーを使うため、保存後も元の形状との依存関係を維持します。

シェルは1つにつながった立体が対象で、少なくとも1面を開けます。複雑な曲面や狭い部分ではOpenCASCADEの厚み計算が成立しない場合があります。

## オフセット平面

「ソリッド → 構築 → オフセット平面」で、基準平面と距離を指定します。XY・XZ・YZに加えて「選択した面」に対応します。「基準面」ボタンを押し、ソリッドの平らな面または構築平面をクリックしてください。先に面や構築平面を選んでから開始すると自動で入力します。斜めの面からも、その面に垂直な距離で平行な平面を作成できます。曲面は選択できません。

距離は正負のmm値で指定します。緑の矢印が正方向を示し、負の値で反対側へ配置します。0 mmも指定できます。XYはZ、XZはY、YZはXの正方向が基準です。面の場合は面の法線方向が基準で、裏面では向きが逆になります。距離欄は小数点以下6桁まで入力でき、グリッドへの丸めは行いません。プレビューを確認して「確定」すると、ブラウザーの「構築」に追加します。

平面を選択して「スケッチを作成」を押すと、その平面に追従するスケッチを開始します。平面の右クリックからも作成でき、スケッチ編集開始時の視点・ズームは維持します。異なる距離の平面に断面を描き、ロフトでつなぐことができます。

平面をブラウザーまたは履歴でダブルクリックすると、距離・基準面・表示サイズを再編集できます。参照したボディの寸法・位置・向きを変更すると、平面、取り付けたスケッチ、その押し出しも追従します。表示サイズは見える枠の大きさだけを変え、スケッチの原点は移動しません。枠の外にも作図できます。参照面を削除した場合などは参照を選び直して修復します。

パネルは左端まで移動でき、折りたたみ・スクロールに対応します。作成・編集によって視点やズームを変えません。キャンセル／Escでプレビューを破棄し、確定後はCtrl＋Zで取り消せます。

新しいオフセット平面は、保存したFCStdをFluxCADの起動後に開いて再計算・編集してください。以前のバージョンで作成した標準FreeCAD形式のオフセット平面は、従来の距離・基準平面の編集画面を継続して使います。`Face-offset-demo.FCStd` に、斜めの面から12 mm離した平面と、その上のスケッチ・押し出しの例があります。曲面からのオフセットや「点まで」の指定は未対応です。

## 中間平面・角度付き平面

「ソリッド → 構築」に2種類を追加しました。

- **中間平面**：平行な2つの平らな面の中央に平面を作ります。同じボディの向かい合う面、別ボディの面、既存の構築平面を選べます。開始後に「面1」「面2」のボタンで順に選択するか、Ctrlで2面を選択してから開始します。非平行な面の二等分平面には未対応です。
- **角度付き平面**：基準平面をXY・XZ・YZ、または「選択した面」から指定します。回転軸をX・Y・Z、または「選択した直線辺」から選び、−180～180度の角度を入力します。軸は基準平面上にある必要があります。例えば、直方体の上面を基準面、その面の直線辺を軸にすると、上面から傾いた平面を作れます。角度の正負で傾く側が変わります。

プレビューを確認して「確定」すると、ブラウザーの「構築」に追加します。平面を選択して「スケッチを作成」でその上に作図できます。小さい面を参照した場合も、平面自体は無限の基準として扱い、表示枠の外にスケッチを描けます。「表示サイズ」は見える枠の大きさだけを変え、スケッチの原点を移動しません。

参照面・辺の位置や寸法を変えると、構築平面、取り付けたスケッチ、その押し出しも追従します。ブラウザーまたは下部履歴の平面をダブルクリックして参照・角度・表示サイズを再編集できます。参照の削除や、平行・面内軸の条件が崩れた場合はエラーになり、参照を選び直して修復します。後続の加工を壊すパネルからの変更は取り消します。

パネルは左端まで移動・折りたたみ・スクロールに対応します。作成・再編集で視点とズームを変えません。キャンセル／Escでプレビューを破棄し、確定後はCtrl＋Zで取り消せます。独自の連動機能を復元するため、保存したFCStdはFluxCADを起動してから開いてください。`Construction-planes-demo.FCStd` に両方の平面と、それに追従するスケッチ・押し出しの例があります。

## 接平面

「ソリッド → 構築 → 接平面」で、円柱または円すいの側面をクリックします。クリックした位置を初期角度として、−180～180度の数値で接する位置を調整できます。先に曲面を選択してから開始することもできます。「曲面」ボタンで参照面を選び直せます。角度は選んだ曲面の基準方向から測るため、必ずしもワールドX方向が0度ではありません。

プレビューの緑の点が接する位置、緑の矢印が平面の正方向です。「法線を反転」で向きを切り替えます。円柱の内面では、元の面に従って内向きが正方向になります。確定するとブラウザーの「構築」に追加され、その平面を選んで「スケッチを作成」を使えます。曲面の横に取付部を描いたり、側面方向の押し出し・切り取りの基準にできます。

参照した立体の半径・位置・向きを変えると、平面、取り付けたスケッチ、その押し出しも追従します。円柱の高さや「表示サイズ」だけを変更してもスケッチの原点は動きません。円すいの高さ・半径の変更は傾斜も変えるため、接平面の向きも更新します。枠は表示範囲で、枠外にも作図できます。法線の反転は原点とX方向を保ち、Y方向とZ方向を反転します。

ブラウザーまたは下部履歴で平面をダブルクリックすると、曲面・角度・表示サイズ・法線を再編集できます。パネルは左右の端まで移動でき、折りたたみ・スクロールに対応します。視点やズームは変えず、キャンセル／Escでプレビューを破棄し、確定後はCtrl＋Zで取り消せます。

対象は解析的な円柱面・円すい面です。球面・トーラス面・自由曲面・STLのメッシュは対象外です。一部だけの円柱面では、その面が存在する角度を指定してください。参照面の削除や形状変更で接平面が成立しなくなった場合はエラーを表示し、参照または角度を選び直して修復します。保存したFCStdはFluxCADを起動してから開いてください。`Tangent-plane-demo.FCStd` に、円柱・円すいの接平面と、その上のスケッチ・押し出しの例があります。

## 3点を通る平面

「ソリッド → 構築 → 3点を通る平面」で、ソリッドの頂点やスケッチの端点を順に3つクリックします。「点1」「点2」「点3」のボタンから選び直せます。別々のボディの頂点、スケッチの端点、単独の頂点オブジェクトを組み合わせることもできます。3頂点をCtrlで先に選択してから開始すると入力済みになります。点の順序はパネルとプレビューの番号で確認してください。

点1が作図面の原点、点1から点2へ向かう方向がX方向になります。3点が揃うと平面のプレビューと、正方向を示す緑の矢印が表示されます。「法線を反転」で表裏を切り替えられます。同じ位置の点や一直線上の3点では平面を定義できないため、別の点を選択してください。円の中心・辺の途中・メッシュの頂点の選択や、点座標の直接入力は対象外です。

確定後はブラウザーの「構築」から平面を選び、「スケッチを作成」で作図できます。元の頂点を寸法変更や移動・回転で変えると、平面・スケッチ・押し出しが追従します。「表示サイズ」は見える枠だけを変え、作図面の原点やX方向には影響しません。3点を含む無限の平面として使えるため、枠の外にも作図できます。

ブラウザーまたは下部履歴で平面をダブルクリックすると、3点・表示サイズ・法線の向きを再編集できます。キャンセル／Escでプレビューを破棄し、確定後はCtrl＋Zで取り消せます。パネルは左右の端まで移動・折りたたみ・スクロールに対応し、視点やズームを変えません。参照が削除されたり3点が一直線になった場合は平面を空にしてエラーを表示するので、点を選び直すか元の形状を修正してください。

保存したFCStdはFluxCADを起動してから開いてください。`Three-point-plane-demo.FCStd` に、高さが異なる3つの柱の頂点を通る平面と、その上のスケッチ・押し出しの例があります。

## パスに沿った平面

「ソリッド → 構築 → パスに沿った平面」で、スケッチの線・円弧・スプライン、または立体の辺をクリックします。その経路上の指定位置に、接線と直角な平面を作ります。ブラウザーからスケッチを選ぶと、つながった経路全体を参照します。辺を選んだ後の「経路全体を使用」でも切り替えられます。立体を丸ごと経路にすることはできません。

- **比率**：経路の始点が0%、終点が100%です。50%なら長さの中央になり、元の経路を長くすると位置も追従します。
- **距離**：始点から経路に沿った長さをmmで指定します。直線距離ではなく、円弧や曲線の長さで測ります。小数点以下6桁まで入力でき、経路が伸びても指定距離は変わりません。
- **終点から測る**：反対側から測定します。面の正方向も逆向きの経路に沿います。青い「S」が現在の測定の始点、緑の矢印が平面の正方向です。
- **面内の回転／法線を反転**：作図面の向きを調整します。法線の反転は原点とX方向を保ち、Y方向とZ方向を反転します。

確定した平面はブラウザーの「構築」に追加されます。平面を選んで「スケッチを作成」で断面を描けます。複数の位置に平面と断面スケッチを作り、ロフトでつなぐ用途などに使えます。位置や元の経路を変更すると、平面、スケッチ、後続の加工が追従します。「表示サイズ」は見える枠だけを変え、原点を移動しません。

直線、円弧、閉じた円、スプライン、枝分かれのない連続した複数の辺に対応します。分離・枝分かれした経路やSTLのメッシュは対象外です。角や折れ目ちょうどの位置では方向を一つに決められないため、位置を角の前後へずらしてください。閉じた経路の始点は経路の持つ継ぎ目で、0%と100%は同じ位置になります。指定距離が経路長を超える場合は確定できません。

ブラウザーまたは下部履歴の平面をダブルクリックして、経路・位置・向きを再編集できます。パネルは左右の端まで移動・折りたたみ・スクロールができ、視点やズームは変えません。キャンセル／Escで破棄、確定後はCtrl＋Zで取り消せます。参照の削除や、距離指定より経路が短くなる変更では平面を空にしてエラーを表示します。参照・位置を選び直すか、元の経路を修復してください。

保存したFCStdはFluxCADを起動してから開いてください。`Path-plane-demo.FCStd` に、円弧の0%・50%・100%に置いた3平面、その上の断面スケッチ、それらをつなぐロフトの例があります。

## 構築軸

「ソリッド → 構築」から、次の2種類の軸を作成できます。

- **円柱・円すいの中心軸**：円柱または円すいの曲がった側面をクリックします。穴の内壁や、一部だけ残った円柱・円すい面も使えます。
- **2点を通る軸**：ソリッドの頂点やスケッチの端点を順に2つクリックします。別々の形状の頂点も使えます。点1から点2へ向かう方向が軸の正方向で、同じ位置の2点は指定できません。2点を先にCtrlで選んでから開始することもできます。

オレンジの線と矢印で位置・方向を確認し、必要なら「軸の方向を反転」を指定して確定します。円柱・円すいの軸の正方向は面の作られ方に従うため、全体座標の＋Z方向とは限りません。「表示長さ」は見える線の長さだけを変え、回転やパターンの基準位置を変えません。線の範囲外でも無限の軸として使えます。

作成した軸はブラウザーの「構築」に追加します。「回転」または「円形パターン」の「軸の指定 → 辺・円筒面・構築軸」を選び、画面上の軸の線、またはブラウザーの軸をクリックしてください。元の形状を移動・回転・寸法変更すると、構築軸と、それを参照する加工が追従します。ブラウザーや履歴で軸をダブルクリックすると、参照・表示長さ・向きを再編集できます。

パネルは左右の端まで移動でき、折りたたみ・スクロールに対応します。視点とズームは自動変更せず、キャンセル／Escでプレビューを破棄し、確定後はCtrl＋Zで戻せます。参照がなくなった場合は軸を空にしてエラーを保持するので、編集から参照を選び直してください。

中心軸の対象は解析的な円柱面・円すい面です。球・トーラス・自由曲面・メッシュは対象外です。2点指定では円の中心や辺の途中の点、座標の直接入力は対象外です。構築軸はスケッチを直接描く面にはできません。

再計算には `model_construction_axis.py` と依存モジュールが必要です。保存したFCStdはFluxCADを起動してから開いてください。`Construction-axes-demo.FCStd` に、中心軸を使った6個の円形パターンと、2点を通る軸を使った270°の回転の例があります。

## 操作

上部メニューはFusion風の3段リボン構成です。ファイル・保存・Undo/Redo、その下に作業タブ、さらに「作成」「修正」「構築」「検査」などのアイコングループを配置しています。各グループ名をクリックすると追加コマンドが開きます。

上下のUIはコンパクト表示です。上部リボンは106論理px、下部履歴は42論理pxに抑えています。アイコンの操作名はマウスを重ねると表示されます。画面の拡大率に応じて物理ピクセル数は変わります。

下段のドキュメントタブと加工履歴は、「ユーティリティ → 表示設定 → 下段タブを表示」のチェックを外すとまとめて隠せます。隠した分だけ作業画面が広がります。同じ項目にチェックを入れると再表示できます。「設定」メニューからも切り替えられ、履歴の右クリックには「下段タブを隠す」があります。表示・非表示の設定は次回起動にも引き継ぎます。タブを隠しても文書や加工履歴は保持します。

左上のブラウザーは「ボディ」「スケッチ」「構築」に分かれています。「ボディ」には加工後の現在の形状が並びます。例えば「押し出し → 切り取り → フィレット」は、最後のフィレットを1つのボディとして選択できます。加工前の形状や切り取りに使った工具は、下部の履歴に残します。非表示にしたボディも一覧には残り、右の目のアイコンで表示を切り替えられます。ボディ番号は元の形状の作成順を引き継ぐため、工具として使われたボディなどの番号が抜ける場合があります。

ブラウザーのボディをクリックして選択し、Mキーまたは右クリックの「移動…」で移動できます。Ctrl＋クリックで複数選択もできます。スケッチはダブルクリックで編集します。ブラウザーの見出しで全体を折りたため、作業画面の大きさやズームは変わりません。移動パネルと重なる場合は、移動中だけブラウザーを隠します。

ブラウザー上部の「ブラウザー」という見出しを左ドラッグすると、好きな位置に移動できます。左右はウィンドウの端まで移動でき、標準パネルが左側にあっても、その上を通って左端に配置できます。上下はリボンと履歴の間に収まります。位置は次回起動にも引き継ぎます。見出しをクリックすると折りたたみ、右クリックの「左上に戻す」でウィンドウの左端へ戻せます。ウィンドウを小さくした場合も、ブラウザーが画面外へ隠れないように位置を調整します。ブラウザーを移動しても、モデルの位置や視点・ズームは変わりません。

下の履歴では、後の加工に使われた形状を薄い文字で表示します。押し出しをダブルクリックすると元の押し出し長さを変更でき、後の切り取り・フィレットも再計算します。「押し出し（切り取り）」などもダブルクリックで距離を変更でき、対称なら全長、両側なら両方向の距離を編集します。スケッチの履歴もダブルクリックで編集できます。ボディと履歴は同じモデルを参照するため、ボディ分けのために形状を複製したり、元の履歴を削除したりしません。

通常は「ソリッド」「サーフェス」「メッシュ」「ユーティリティ」を使い、「スケッチ」タブは編集中だけ表示します。「シートメタル」「プラスチック」「管理」は未実装のため無効表示です。「設定」からFreeCAD標準メニューバーを表示したり、標準UIへ戻したりできます。

3Dビューとスケッチ編集で、同じグリッドの間隔・色・原点を使います。初期状態はXY平面で、赤がX軸、緑がY軸です。「ユーティリティ → 表示設定」の「グリッド」、または「設定 → 表示」メニューで表示を切り替えられます。別の作図面を編集すると、その面の座標系を使用し、編集終了後も維持します。

間隔は初期状態でズームに追従し、従来より細かく表示します。自動調整の細かさは「標準（従来）」「細かい」（初期値）「さらに細かい」から選べます。例えば従来2 mmになるズーム位置で「細かい」は0.5 mm、「さらに細かい」は0.2 mmになる場合があります。編集開始時に間隔や視点をリセットしません。

「設定 → 表示 → グリッド設定…」、または「ユーティリティ → 表示設定 → グリッド設定…」で変更できます。スケッチ編集中は右側パレットにも同じ間隔欄があります。自動調整中でも数値を直接入力でき、Enterまたは別の欄へ移って確定すると自動調整がオフになり、その間隔に固定します。0.001 mm単位で入力でき、入力途中の小数は定期更新で消えません。設定画面では最後に「OK」で適用し、「キャンセル」では変更しません。両方にある「0.1 mm」「0.5 mm」「1 mm」ボタンでも直接固定できます。固定間隔ではズームしても間隔は変わりません。「グリッド間隔を自動調整」をオンにするとズームに追従する表示へ戻ります。自動・手動の選択、細かさ、手動間隔は通常表示にも共通で、次回起動にも引き継ぎます。パレットでは自動拘束やスライス表示も変更できます。

「グリッドにスナップ」は初期状態でオンです。作図点が近くのグリッド交点に吸着し、グリッド間隔を変えると吸着間隔も変わります。オフにすると自由な座標で作図できます。スナップのオン・オフは次回起動にも引き継ぎます。既存の点・線への吸着はグリッドより優先されます。グリッドを非表示にしてもスナップ設定は保持されます。

スケッチパレットの「スナップを強める」も初期状態でオンです。線・長方形・円弧などの作図中に、少し離れた格子点にも吸着しやすくします。既存の頂点や辺への吸着を優先し、数値入力や通常の選択・ドラッグ操作には影響しません。オフにすると従来の弱い吸着に戻り、設定は次回起動にも引き継ぎます。

常に1 mm刻みで描く場合は、パレットの「1 mm」ボタンを押すか、「グリッド間隔」に1を入力してEnterを押してください。0.5 mm、0.1 mmなども指定できます。格子点が画面上で重なるほど細かい場合は、拡大してから描いてください。

スケッチ用の作成・修正・拘束ボタンは、編集を開始すると有効になります。作図・拘束・グリッドスナップはFreeCADのソルバーと標準機能を使用します。

更新を反映するにはFluxCADを起動し直すか、FreeCADのマクロ画面から `FluxCAD.FCMacro` を再実行してください。再実行は開いている文書を保持します。

視点操作はソリッドとスケッチ編集で共通です。中ボタンドラッグで移動、Shift＋中ボタンで自由回転、ホイールでカーソル位置を中心にズームします。Ctrl＋Shift＋中ボタンの上下ドラッグでもズームできます。中ボタンのダブルクリックは、現在の向きを維持して全体表示します。

右上のビューキューブも、左ボタンでつかんでドラッグすると自由に回転できます。ボタンを離すとその角度で止まり、ズーム倍率・形状の配置・選択は保ちます。短く面・辺・角をクリックすると従来どおりその方向へ切り替わり、周囲の矢印も使えます。スケッチ編集中、移動モード、押し出しやメッシュ加工のプレビュー中も操作できます。ドラッグ中のEscは、その時点の向きで回転操作を終了します。

立体そのものを移動するには、画面上またはブラウザーの「ボディ」で選択して「修正 → 移動（ドラッグ）」、またはMキーを押します。左ボタンを押したままドラッグすると、画面に沿って立体が動き、ボタンを離すと確定します。Ctrlで複数選択してから始めると、位置関係を保ってまとめて動きます。移動モード中は作業画面の空白からでもドラッグできます。

画面上部のX・Y・Zボタン、または3Dビューで同じキーを押すと、原点の軸方向に固定できます。「画面に沿う」ボタンまたはVキーで自由な方向へ戻ります。軸を真正面から見ている場合は、マウスの上下で奥行き方向に移動します。ドラッグ中のEscはその移動を取り消し、移動モードを終了します。確定後のEscはモードだけを終了します。Ctrl＋Zで直前のドラッグをまとめて元に戻せます。

移動パネルで「配置先の座標」を選ぶと、最初に選択した立体の配置原点のX・Y・Z座標を指定できます。「現在位置からの移動量」では、X・Y・Z方向の移動距離を指定します。数値を入力して「数値を適用」、または入力欄でEnterを押してください。単位はmmで、負の値と小数にも対応します。ドラッグ後もパネルに現在座標が表示され、そのまま数値で位置を修正できます。複数選択時は同じ移動量を全ての立体に適用し、位置関係を維持します。

立体移動の「グリッドにスナップ」は初期状態でオン、間隔は1 mmです。移動量ではなく、最初に選択した立体の配置原点を、全体座標の整数mmの位置に合わせます。例えばX=0.3 mmから動かしても、1.3、2.3ではなく1、2 mmの位置へ吸着します。X・Y・Zに固定したときは、その軸だけを合わせます。正面からの自由ドラッグでは奥行き方向を保持します。間隔は0.1 mm、0.5 mmなどにも変更でき、次回起動にも引き継ぎます。数値入力にはスナップをかけないので、1 mmスナップを有効にしたまま12.25 mmなどを正確に指定できます。

スナップ中は全体座標のXYグリッドを指定した間隔で表示し、ズームしてもスナップ間隔は変わりません。移動を終了すると従来のグリッド設定と作図面に戻ります。基準は配置原点であり、クリックした点や形状の角ではありません。移動パネルの「基準」で対象を確認してください。

「修正 → 数値で移動…」からも、現在位置からの移動量を入力できます。数値指定は全体のX・Y・Z軸を基準とし、視点の向きには依存しません。ドラッグと数値指定のどちらも押し出し元のスケッチの位置を保持し、寸法変更への追従を維持します。スケッチ編集を終了してから使用してください。

回転中心は選択した面・エッジ・形状を優先し、未選択なら表示中の形状の中心を使用します。「設定 → マウス操作」で自由回転とズーム方向の反転を設定できます。自由回転をOFFにするとZ軸基準の回転になります。スケッチを傾けた後は、パレットの「ビュー正面」で作図面に戻れます。

キー割当の参考：[Autodesk公式のFusion操作一覧](https://www.autodesk.com/products/fusion-360/blog/quick-tip-pan-zoom-orbit-preferences/)。独自の右クリックマーキングメニュー、クリック位置による回転中心の指定、タッチジェスチャーは未実装です。

長方形の幅・奥行はスケッチの `Constraints > Width / Height`、押し出しは `Length Fwd`、円柱は `Radius / Height` で変更できます。新しい穴は履歴のダブルクリックで専用パネルを開いて変更します。旧版のZ方向の穴は、標準ツリー内の工具の半径・Placementで変更します。

画面上の立体と下部の履歴では、Ctrl＋クリックで複数の形状を選択できます。同じ形状をCtrl＋クリックすると、その形状だけ選択を解除します。通常のクリックでは選択を置き換えます。履歴の選択表示は画面上の選択にも追従します。「結合」「切り取り」では、先に対象ボディ、次に工具ボディを選ぶと、その順序で専用パネルが開きます。

下部は加工履歴です。履歴の巻き戻し・フィーチャー抑制は未実装です。詳細なプロパティの編集は「FreeCAD 標準UIに戻す」から標準のツリーとデータ欄を使用できます。形状の依存関係も保持されます。

## 複数ボディの結合・切り取り・交差

「ソリッド → 修正 → 結合／切り取り／交差部分を残す」で、対象1個と工具1個以上を指定し、プレビューしてから確定できます。何も選ばずに開いて、画面で対象・工具を選ぶこともできます。

1. 「対象ボディ」を一覧または「対象を画面で選択」で指定します。先に複数選択した場合は最初のボディが対象です。
2. 「工具ボディ」の一覧にチェックを入れます。「工具を画面で選択」では、ボディのクリックごとに追加・解除でき、Ctrl＋クリックも使えます。選択後に「工具の選択を完了／プレビュー」を押します。
3. 「操作」を選びます。「結合」は全体を合わせ、「切り取り」は対象から工具の部分を除きます。「交差部分を残す」は対象と工具全体が重なる部分を残します。工具が複数ある場合は工具の和集合を使うため、離れた複数の工具との重なりも残せます。
4. 「工具ボディを保持」をONにすると、確定後も工具が独立したブラウザー項目として残ります。OFFでは工具を加工前の履歴へまとめます。どちらでも参照データは保存し、元ボディや工具の寸法・配置の変更に追従します。
5. 青いプレビューと立体数・体積を確認し、「確定」を押します。プレビューは加工結果を表示し、保持した工具は確定後に表示します。

履歴または完成したボディをダブルクリックすると、操作・工具の追加削除・工具保持を再編集できます。右クリックの「操作と工具を編集…」からも開けます。編集時は元の対象ボディを維持し、結果の移動・回転・名前・色も保持します。工具を選び直す間は元形状を一時表示します。外した工具は、他の加工に使われていなければ独立したボディに戻ります。

確定は1回のCtrl＋Zで取り消せます。キャンセル・Esc・別コマンド・別文書への切り替えでは、元の表示・選択へ戻します。視点とズームを自動変更せず、パネルはタイトルをドラッグして端まで移動・折りたたみできます。後の加工が成立しなくなる再編集は全体を取り消します。パネルを開いている間に元形状が変更された場合は、キャンセルして開き直してください。

対象はソリッドです。メッシュ、同一ボディの重複、加工前後の依存するボディ同士、結果や後の加工への循環参照には対応しません。切り取りで工具が食い込まない場合や、結果に立体が残らない場合は確定できません。結果が複数の離れた立体になる場合も、全体で1つのブラウザー項目として扱います。以前の即時確定方式で作った結合・切り取りは、そのまま標準FreeCADのフィーチャーとして維持します。

新しい結合操作は `model_combine.py` を使用します。保存したFCStdは **FluxCADを起動してから開いてください**。完成形状の受け渡しにはSTEP/STLを使用できます。

## コンポーネントとジョイント

「ソリッド → アセンブリ」に、コンポーネントの作成・複製・接地、固定ジョイント、回転ジョイント、スライダージョイント、ジョイントの解除があります。**現在の配置を基準に接続する方式**です。先に「移動 / コピー」や「位置合わせ」で部品を配置してください。

1. 元になるボディを1つ以上選び、「コンポーネントを作成…」を開きます。一覧にチェックし、必要なら名前と「接地」を指定して確定します。ボディ1つにつき1コンポーネントを作ります。元ボディは標準では非表示になり、履歴とブラウザーに残ります。
2. 同じ形を増やすには、作成した部品を選び「コンポーネントを複製」を使います。元ボディの寸法変更は複製にも反映され、各部品の位置は独立します。自由な部品はMでドラッグ／座標指定、「移動 / コピー」で数値回転できます。元ボディやその親コンテナの移動では、既存の部品位置は変わりません。
3. 動かさない基準部品は「接地 / 接地を解除」で固定します。ブラウザーの「コンポーネント」をダブルクリックしても、名前と接地状態を編集できます。
4. 動く部品、基準部品の順にCtrlで2つ選び、「固定ジョイント…」「回転ジョイント…」「スライダージョイント…」のいずれかを開きます。パネルの選択欄から指定しても構いません。固定ジョイントは現在の相対位置・向きを保持し、基準部品の移動・回転に追従します。
5. 回転ジョイントは角度を数値またはスライダーで変更できます。「可動範囲を制限」を有効にして最小・最大角度を設定できます。0°は最初に接続したときの姿勢です。軸のX/Y/Z・任意方向と原点は**基準部品のローカル座標**です。「辺・円筒面から軸を取得」を押し、直線の辺または円筒の側面をクリックして指定することもできます。
6. スライダージョイントは、部品の向きを保って指定した軸方向へ平行移動します。**移動距離をmmで入力**するかスライダーを動かします。「移動範囲を制限」を有効にすると最小・最大距離を指定できます。例えば0〜40 mmならその範囲だけで往復します。正の距離は緑の矢印方向、負の距離は反対方向です。0 mmは接続時の位置で、全体座標の原点ではありません。X/Y/Z・任意方向は基準部品のローカル座標で、直線の辺や円筒面から方向を取得する操作も使えます。軸の位置は平行移動に影響しません。

ブラウザーの「ジョイント」または下段履歴をダブルクリックすると再編集できます。複数段の接続にも対応し、基準部品の変更が接続先へ順に反映されます。プレビュー中は元の配置と視点を保持し、確定で一括反映します。キャンセル・Esc、Ctrl＋Z／やり直しにも対応します。操作パネルはタイトルをドラッグして画面端まで移動でき、折りたたみ・スクロールが使えます。

接地した部品やジョイントで動く部品はMで直接移動できません。接地を解除するか、ジョイントの角度・距離を変更してください。「ジョイントを解除」は、その時点の位置・向きを残して自由な部品に戻します。接続先を変える場合も一度解除して作り直します。固定・回転・スライダーの種類は再編集で切り替えられ、固定に戻すと元の0°／0 mmの相対姿勢を使います。角度と距離、それぞれの制限値は別々に保存します。不正な角度・距離や削除された参照で接続が成立しない場合は、ブラウザーに赤い警告を出し、接続先の古い形状を消します。設定の修正または解除で復旧できます。

**動作例**：FluxCADを起動して `Assembly-demo.FCStd` を開き、「ジョイント」の **Arm rotation** をダブルクリックしてください。接地した台座、固定された軸、±90°で回転する青いアームの3部品です。最初は30°で保存しています。

**直線移動の例**：`Slider-demo.FCStd` の「ジョイント → **Carriage travel**」をダブルクリックします。青いスライダーが0〜40 mmの範囲でレールに沿って動きます。初期位置は15 mmです。距離は小数点以下6桁で入力でき、±1000000 mm以内に制限しています。最小値と最大値を同じにすると、その距離に固定できます。

以前の固定・回転ジョイントを含むFCStdもそのまま開けます。新しい距離項目は、ジョイントの編集を確定したときに追加し、キャンセルでは元データを変更しません。

対応範囲は、同じ文書のルート階層に置く1ボディ単位の部品と、1部品につき1つの接続元を持つ固定・回転・スライダージョイントです。これらを複数段で混在させられます。閉じたリンク機構、入れ子のアセンブリ、複数拘束の同時解決、ドラッグでの関節駆動、接触・衝突計算、面を自動で合わせるジョイントは未対応です。取得した辺・円筒の軸は取得時の座標を保持し、形状の変更に追従する参照ではありません。必要に応じて再取得してください。元ボディの既存寸法編集には追従しますが、その後に追加した別フィーチャーへ参照先を自動変更しません。「移動 / コピー」の通常コピーは独立したボディになり、部品の関連複製には専用の「コンポーネントを複製」を使います。

保存には `model_assembly.py` のPythonプロキシを使用します。**FluxCADを起動してからFCStdを開いてください**。完成部品を選択してSTEP/STLへ出力すると現在の配置で形状を渡せますが、ジョイントの設定はSTEP/STLには入りません。

## 球・トーラス・コイル・パイプ

「ソリッド → 作成」に4種類を追加しました。寸法とX/Y/Z位置を数値で指定し、プレビューを確認して確定します。新規ボディとして作成するので、必要に応じて「修正 → 結合」や切り取りを使えます。作成・再編集で視点やズームは変更しません。

- **球**：直径と中心位置。
- **トーラス**：中心径と断面直径。中心径は管の中心を通る円の直径で、外径は「中心径＋断面直径」です。
- **コイル**：中心径、丸線の線径、ピッチ、巻き数、右巻き／左巻き。中心線の高さは「ピッチ×巻き数」です。巻き数は0.25～50回、小数にも対応します。端面は線に直角で、ばねの端を平らに研削する処理は含みません。巻きが接触する寸法は確定できません。
- **パイプ**：外径と肉厚。「直線（長さを指定）」では長さと軸方向を指定できます。輪郭が1本につながったスケッチを先に選ぶと、その経路に沿う中空パイプになります。パネルの「経路」からも選べます。円弧、閉じた円、3次元のワイヤ経路に対応し、経路の寸法・配置変更に追従します。鋭い角は留め継ぎになります。複数の離れた輪郭、枝分かれ、自己交差する管は対象外です。内径は「外径－肉厚×2」で、両端はふさぎません。

トーラス・コイル・直線パイプは作成時にX/Y/Z軸を選べます。経路パイプのX/Y/Zは経路からの追加オフセットです。作成後はブラウザーのボディ、または下段履歴をダブルクリックして寸法・位置を再編集できます。既存の回転は保持し、向きを変える場合は「移動 / コピー」を使います。パネルはタイトルをドラッグして画面端まで移動でき、折りたたみ・スクロールにも対応します。キャンセル・Escで破棄、Ctrl＋Zで確定した作成や編集を取り消せます。

球とトーラスはFreeCAD標準フィーチャー、コイルとパイプは `model_primitives.py` によるパラメトリック形状です。**保存したFCStdはFluxCADを起動してから開いてください。** 完成形状はSTEP/STLに出力できます。丸線以外のコイル断面、可変ピッチ、円形以外のパイプ断面、立体の辺を個別に集めた経路の指定は未対応です。

4種類の例を並べた `Primitives-demo.FCStd` も同梱しています。

## パスに沿ったパターン

「ソリッド → 作成 → パターン → パスに沿ったパターン」で、ボディをスケッチやワイヤの経路に沿って複製します。

1. ボディと、線が1本につながった経路スケッチを選んでコマンドを開きます。パネルの一覧から指定することもできます。
2. 元を含む個数を2～200個で指定します。「経路全体」は全長に等間隔、「間隔」は隣り合う複製どうしの距離、「全体の距離」は最初から最後までの距離です。いずれも経路に沿った長さで計算します。
3. 「向きを保つ」は同じ向きで平行移動し、「経路に合わせる」は経路の接線に沿って回転します。「経路を逆向きにたどる」で進行方向を変えられます。プレビューの緑の矢印と座標表示で始点を確認できます。
4. 確定後はブラウザーまたは履歴をダブルクリックして、元のボディ・経路・個数・距離・向きを再編集できます。キャンセル・Escでは変更せず、Ctrl＋Zで作成や編集を取り消せます。視点・ズームは変更しません。

元ボディの位置は保持し、経路の始点からの変化量を使って複製します。**経路そのものの上へ並べる場合は、先に元ボディを経路の始点へ配置してください。** 経路だけを平行移動しても、始点からの変化量は同じなので複製の配置は変わりません。元ボディの移動や寸法変更、経路の長さ・曲がり・向きの変更はパターンへ反映されます。

直線、円弧、閉じた円、スプライン、3次元ワイヤに対応します。閉じた経路を全体に使う場合は始点を重複させず、一周に等間隔で配置します。経路を超える距離や、間隔指定で最後が始点に重なる設定は確定できません。元ボディが複数の立体を含む場合は、まとまりを保って複製します。結果は1つのパターン項目として移動できますが、立体どうしを結合した形状ではありません。必要に応じて後から結合します。立体の重なりの自動解消は行いません。

対応する経路は枝分かれのない連続した輪郭1本です。複数ボディの個別選択、加工フィーチャー単位のパターン、立体の辺を個別に集めた経路、個々の複製の抑制は未対応です。合計の立体数は2000個までです。元ボディや経路が削除された場合は古い形状を消し、同じパターンの再編集から参照を選び直せます。

`Path-pattern-demo.FCStd` は、直線と円弧をつないだ経路に18個のボディを並べたサンプルです。この機能は `model_path_pattern.py` を使うため、保存したFCStdはFluxCADを起動してから開いてください。完成した立体はSTEP/STLへ出力できます。

## スケッチの投影・交差と寸法

FreeCAD 1.1.3にある標準のスケッチ機能をリボンから使えるようにしました。

- **投影**：「スケッチ → 作成 → 投影 / 含める → 投影」を開き、表示されている別のスケッチやボディの辺・頂点・面をクリックします。面を選ぶと境界を投影します。編集中の平面に取り込み、元形状の変更に追従します。
- **交差**：同じサブメニューの「交差」で、スケッチ平面を横切る面や辺を選びます。例えば直方体の途中にあるスケッチでは、側面を順に選ぶと断面の輪郭を取り込めます。
- 取り込みを終えるときは「選択（作図を終了）」を押します。参照するボディが見えない場合は、ブラウザーの目のアイコンで表示してください。投影した形状自体をドラッグして変更することはできません。形は参照元を編集します。
- 投影した辺を選んで「修正 → 補助線に切替」を使うと、位置決め用の補助線と輪郭用の線を切り替えられます。補助線ではない閉じた輪郭は、スケッチを終了した後に領域選択して押し出せます。取り込み時の補助線設定はFreeCAD側の設定に従います。
- **寸法**：線・円・円弧などを選び、「作成 → 寸法」を押します。寸法の表示位置をクリックして数値を入力します。配置中はMキーで候補の寸法種類を切り替えられます。「作成 → 寸法の種類」では長さ・距離、水平距離、垂直距離、半径、直径、角度を直接指定できます。
- **参照寸法**：寸法の文字を選び、「拘束 → 駆動寸法 / 参照寸法に切替」を使います。駆動寸法は形状を決め、参照寸法は測定値を表示します。投影形状の測定にも使えます。拘束済みの形状へ寸法を追加する際は、過剰拘束に注意してください。
- **点を線上に拘束**：「選択」で点と線・曲線をCtrl＋クリックし、「拘束 → 点を線上に拘束」を使います。投影した辺を基準にして点を配置することもできます。

これらはFreeCAD標準の外部ジオメトリ・寸法拘束として保存されます。元の形状を削除したり参照先の辺・面の構成が大きく変わった場合は、参照の修正が必要になることがあります。現在のスケッチに依存する後工程の形状は、循環参照になるため取り込めません。

`Sketch-projection-demo.FCStd` は、直方体の上面を投影して押し出した例です。元の直方体の長さを変更すると、投影輪郭と押し出しが追従します。断面の交差と寸法の例も同じファイルに入っています。

## スケッチ内のミラー・パターン・編集

スケッチを編集中に、上部の「選択」で作図を止め、対象の線・円などを選んでから実行します。複数の図形はCtrl＋クリックで選びます。これらはFreeCAD標準Sketcherの機能です。

- **ミラー**：「作成 → ミラー」。図形を選んで実行し、水平軸・垂直軸などの鏡映の基準をクリックします。操作パネルで元図形の削除と対称拘束の作成を指定できます。
- **矩形状パターン**：「作成 → パターン → 矩形状パターン」。列数・行数を指定してから配置位置をクリックします。列3、行2は元を含めて6個です。最後に選んだ点が基準になります。等間隔・間隔拘束・クローンの設定は標準ダイアログに従います。
- **回転 / 円形状パターン**：「作成 → パターン」または「修正」から実行します。回転中心、基準方向、回転先の方向の順にクリックします。「コピー」が0なら元図形を回転し、3なら元に加えて3個の複製を作成します。
- **移動 / 配列**：「修正 → 移動 / 配列」。基準点と移動先をクリックします。標準パネルのコピー数が0なら移動、数を増やすと複製になります。行数を増やすと2方向の配列も使えます。
- **コピー**：「修正 → コピー」。図形と基準となる点を選び、点を最後に選択してから実行し、コピー先をクリックします。
- **尺度**：「修正 → 尺度」。拡大縮小の中心、基準距離を決める点、倍率を決める点の順にクリックします。中心から10 mmの位置、20 mmの位置と指定すると2倍です。「元のジオメトリを保持」で元図形も残せます。
- **分割**：「修正 → 分割」。分割したい辺の位置をクリックすると2本に分かれます。
- **面取り**：「修正 → 面取り」。角を選んで面取りの大きさを指定します。「角を維持」の状態により補助図形も残る場合がありますが、押し出し輪郭には面取りした線が使われます。
- **角丸長方形**：「作成 → 長方形 → 角丸長方形」。対角の2点と角丸めの大きさを指定します。
- **円弧スロット**：「作成 → スロット → 円弧スロット」。円弧の中心・始点・終点と幅を指定します。

「選択（作図を終了）」で操作を取り消して選択に戻れます。確定した変更はCtrl＋Zで取り消せます。固定済みの図形や他の図形と拘束でつながった図形では、移動・拡大縮小が制限されたり、拘束の調整が必要な場合があります。パターン結果はスケッチ図形・拘束として保存され、Fusionの独立したパターンフィーチャーとは編集方法が異なります。

`Sketch-transforms-demo.FCStd` に各操作の結果を保存しています。ブラウザーで対象のスケッチを表示して編集できます。

## 範囲と制約

- 直方体、円柱、球、トーラス、丸線コイル、中空パイプ、XY長方形スケッチ、自由スケッチ、プレビュー付き押し出し（新規・結合・切り取り・交差）、回転、ロフト、スイープ、直線・円形ボディパターン、ミラー、シェル、立体のドラッグ・数値指定移動、ボディの数値指定回転と独立コピー、平面・円筒面どうしの位置合わせ、面に垂直な穴あけ（貫通・深さ指定）、エッジフィレット、等距離・2距離面取り、平面によるボディ分割、結合、切り取り。
- 回転・円形パターンは全体座標軸、直線の辺・円筒面の参照軸、数値指定の任意方向に対応します。矩形状パターンは全体座標軸です。回転は新規ボディを作り、必要に応じて後から結合・切り取りを使います。
- 「穴」はソリッドの平面を基準にする通常の穴・ザグリ穴・皿穴・メートルねじ穴に対応します。曲面からの穴あけ、外ねじ、メッシュの穴あけは未対応です。
- 押し出しは距離・面まで（平面）・貫通切り取りに対応し、各範囲で正負の勾配角・開始オフセットと同じスケッチの複数領域を使用できます。距離指定では両側別角度、面まででは終点オフセットにも対応します。ドラッグハンドル、曲面までの押し出しは未実装です。
- 新しい貫通穴はボディ厚さの変更に追従します。旧版のZ方向の穴は、従来どおり工具のHeightを手動調整する方式です。
- 結合・切り取り・交差は、対象1個と工具1個以上を指定し、プレビュー、工具保持、履歴編集に対応します。
- 閉じていないスケッチや大きすぎるフィレット半径ではエラーを表示し、作成操作を取り消します。
- 自由スケッチの作図・拘束ルールはFreeCAD標準です。視点操作はFluxCADの共通操作を使用し、ソリッド用のE/H/Fショートカットはスケッチ編集中は無効になります。
- コンポーネントの作成・関連複製・接地と、現在の配置での固定／回転／スライダージョイントに対応します。高度なアセンブリ、CAM、クラウド、Fusion形式の直接読込はありません。
- 「軽量」はUIと追加コードの小ささを意味します。FreeCAD本体は必要で、本体サイズ・メモリ使用量の削減はまだ行っていません。

## 図面ワークスペース（TechDraw）

左上の **デザイン ▼ → 図面** で製図に切り替えます。FreeCAD標準のTechDrawで、元モデルと関連した図面を作成します。

1. **用紙 → 新規図面**：A4 / A3横向き、図面名、尺度の倍率、第一角法 / 第三角法を指定します。日本語・英語のメニューに対応しています。
2. ブラウザーで元のボディ・スケッチ・サーフェスを選び、**作成 → ベースビュー** または **三面図**。Ctrlで複数のモデルを選択できます。三面図は正面・上面・右側面をひとつの投影グループとして作ります。
3. 基準方向、用紙の尺度に従うか個別の倍率を使うか、隠線表示、X・Y位置を設定します。X・Yは用紙左下からのmmです。図の枠をドラッグして配置することもできます。**修正 → 図の枠を表示 / 非表示** で枠を切り替えます。
4. **図面上の辺** を選び、**寸法** から長さ・水平・垂直・半径・直径・角度寸法を記入します。2点間や2辺間はCtrlで追加選択します。寸法は元モデルの大きさを表し、図の表示倍率を変更しても値は変わりません。寸法文字をドラッグして配置し、ダブルクリックでFreeCAD標準の寸法編集を開けます。
5. **注記 → 注記** で複数行の文字、位置、文字高さを入力します。**出力 → PDF出力 / SVG出力** で現在の用紙を出力します。

ブラウザーの「図面」には用紙、投影図、寸法、注記を親子関係で表示します。用紙のダブルクリックで開き、投影図・注記のダブルクリックで数値を編集します。**用紙 → 用紙設定** では尺度・投影法・表題欄の文字を編集できます。用紙の尺度は「用紙に従う」図へ適用されます。**デザインに戻る** で3D画面へ戻ります。3Dの視点・ズームは維持します。下段タブを隠していても、ブラウザーまたは「図面を開く」から用紙を開けます。

枠の切り替えを使用すると、TechDrawの枠表示設定を手動モードにします。図形の変更や尺度変更後は投影の計算が完了してから寸法値が更新されます。

すべて標準のTechDrawオブジェクトと関連付けで保存し、専用のPythonプロキシは使いません。テンプレートはFCStdに埋め込まれ、通常のFreeCADでもモデル変更に応じて図面・寸法が更新されます。辺の削除や大きな形状変更で番号が変わった場合は寸法参照の修復が必要です。

付属の `samples/Drawing-demo.FCStd` で確認できます。PDF/SVGは図面の出力操作で生成できます。書式は独自の簡易テンプレートです。製図規格への完全準拠を保証するテンプレートではありません。幾何公差・部品表や、既存投影図の元モデルの差し替えはまだ専用メニューの対象外です。通常のFreeCADのTechDrawには別途利用できる機能があります。

配布時は `templates` フォルダも必要です。新規図面のA4 / A3用紙を作る際に使用します。

### 断面図・詳細図・中心線

- **作成 → 断面図**：図面またはブラウザーで元の投影図を選びます。標準タスクで識別文字（例：A）、方向ボタン、切断原点X・Y・Zを指定し、「今すぐ更新」で確認してOK。原点は3Dモデルの座標です。切断線と矢印が元ビューに表示されます。三面図のグループを選んだ場合は基準の正面図を使用します。
- **作成 → 詳細図**：元の投影図を選び、拡大範囲の中心X・Y、半径、倍率、参照文字（例：B）を指定します。「注目位置をドラッグ」でも中心を動かせます。中心は元ビューの中心からの座標で、用紙上の位置ではありません。確定後の配置は図の枠をドラッグするか、下記の数値設定を使います。
- **修正 → 図の配置と表示**：投影図・断面図・詳細図を選び、用紙上のX・Y、キャプション、輪郭線幅、白抜き表示を設定します。投影グループの子ビューはグループからの相対位置です。断面図では切断面の表示方式、幾何ハッチングのパターン、尺度、角度も変更できます。
- **注記 → ハッチング**：図面上の面内部を選び、パターン、尺度、角度、線幅、色を指定します。作成したハッチングはブラウザーの元ビューの下に表示され、ダブルクリックで再編集できます。
- **注記 → 中心マーク**：図面の円・円弧を選び、2本の中心線を追加します。**2辺間の中心線** は同じビューの2辺をCtrlで選択、**面の中心線** は面内部を選択して起動します。標準タスクで方向・延長量・線種などを設定します。
- **修正 → 補助線を削除**：図面上の中心マーク・補助線を選んで削除します。モデルから投影された輪郭そのものは削除しません。Ctrl+Zで戻せます。

断面図・詳細図をダブルクリックすると標準タスクで切断位置や拡大範囲を再編集できます。タスクをOK／キャンセルで閉じてから次の操作に進んでください。断面図・詳細図は元モデルに追従する標準TechDrawデータです。ハッチングのパターンもFCStdに埋め込まれます。中心マークは図面の補助線として保存するため、形状や円の位置を変更した後は位置を確認し、必要なら再作成してください。大きな形状変更で面・辺番号が変わったときはハッチング・寸法・中心線の参照も確認してください。

断面図・拡大図・中心線・ハッチングは、上記の操作で作成できます（詳細図の開発用デモは初回公開版には含めていません）。用紙の尺度と異なる詳細図の倍率は、キャプションなどにも明記してください。

出力例のPDFは描画確認済みです。ただし、FreeCAD 1.1.3の標準PDF出力には空の色指定（SCN）が含まれる場合があり、Popplerの厳密な読み取りで警告が出ます。検証例では図形・文字を描画できていますが、厳密なPDF形式検査への適合は残件です。

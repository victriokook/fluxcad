# FullArcCAD 0.2.242 Linux preview1

旧FluxCADの名称をFullArcCADへ変更した最新Linux x86_64試作版です。座標構築点・座標と方向の構築軸・各種メッシュ機能を含む採用済み343モジュールから作成しました。

## Download / ダウンロード

- `FullArcCAD-0.2.242-linux-preview1.tar.gz`: 最新Linux実装ソース・起動スクリプト・アドオン・検証記録
- 同名`.sha256`: 配布物ハッシュ
- `FullArcCAD-Linux-Introduction-ja.mp4`: 新規72秒・日本語字幕のLinux紹介動画（音声なし）
- `FullArcCAD-Linux-Thumbnail.png`: 紹介動画サムネイル

```sh
sha256sum -c FullArcCAD-0.2.242-linux-preview1.tar.gz.sha256
tar -xzf FullArcCAD-0.2.242-linux-preview1.tar.gz
cd FullArcCAD-0.2.242-linux-preview1
sh Start-FullArcCAD.sh --freecad /absolute/path/to/FreeCAD.AppImage --language ja
```

FreeCAD本体・Python3・日本語フォントは別途必要です。FreeCADバイナリやフォントの自動ダウンロードはしません。

## Validation / 検証

公式FreeCAD1.1.3 AppImage / Ubuntu24.04 / Xvfb / Mesa、ネットワーク無効の専用コンテナで実行。

| Scope | Result |
|---|---|
| Native geometry + integration + mesh + coordinate points/axes | 199 cases + 76 guards PASS |
| Japanese/English Qt: mesh section + coordinate axis + exact logo label | 78 cases total / 38 actual QAction launches PASS |
| Launcher path/environment/stale-report tests | 18 PASS |
| Archive payload SHA256 / executable shell / Linux extraction | PASS |
| Physical GUI input / Wayland / real GPU / high DPI / other distros | NOT TESTED |

Selected tests only;not all343 module functionality. Complete evidence and limits are in `LINUX-VALIDATION.json`, `LINUX-BUILD.json`, `linux-tests/results` inside the package. Exact SolidWorks BRep conversion is unavailable on Linux;STEP import is separate. Legacy FluxCAD config/env/storage identifiers retained. No full Windows/Linux parity claim.

The introduction is an actual Linux virtual-display/API-driven synthetic demo with captions,not physical GUI input footage. The CAD assets are generated specifically for this demo;no user/private CAD or external music.

**Use the attached tar.gz for the current Linux implementation. Automatic Source code archives refer to the repository's older Windows application baseline.** Existing Windows0.2.122 and Linux0.2.234 assets are preserved. MIT with third-party notices retained;FreeCAD is separately distributed. Not an Autodesk/Fusion product.

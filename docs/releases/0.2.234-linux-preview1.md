# FluxCAD 0.2.234 Linux preview1 / Linux試作版

Linux x86_64向けの試作版です。FreeCAD 1.1.3で選択したnative・日英Qt試験に合格しています。**物理GUIは未確認、全機能・Windows版との完全同等性は未保証です。**

## ダウンロードと起動 / Download and launch

- `FluxCAD-0.2.234-linux-preview1.tar.gz` — Linux実装ソース・起動スクリプト・同梱アドオン・検証記録（約2.7 MB）
- 同名`.sha256` — 配布物のSHA256
- FreeCAD本体とフォントは同梱しません。公式Linux FreeCAD 1.1.xとPython3を別途用意してください。

```sh
tar -xzf FluxCAD-0.2.234-linux-preview1.tar.gz
cd FluxCAD-0.2.234-linux-preview1
sh Start-FluxCAD.sh --freecad /absolute/path/to/FreeCAD.AppImage --language ja
```

[日本語の起動手順](https://github.com/victriokook/fluxcad/blob/main/docs/Linux-preview-ja.md) · [English setup](https://github.com/victriokook/fluxcad/blob/main/docs/Linux-preview-en.md)

Ubuntu 24.04 Docker + Xvfb + Mesa、公式FreeCAD 1.1.3 AppImage（SHA256確認済み）で実行しました。仮想画面のQt自動操作・描画を物理GUI確認とは扱いません。

## 制限 / Limitations

- **SolidWorks厳密BRep取込はLinux未対応。** Windows専用decoder/workerは同梱せず、実行前に拒否します。STEP標準取込とは別の制限です。保存表示メッシュ取込は残っていますがLinux未検証です。
- Linuxの初期フォントはローカルのNoto CJK等から検出します。Windowsフォント参照のある文書で文字を再生成するには、対応するローカルフォントの指定が必要です。
- 原本追従等の個別機能制限は同梱文書を参照してください。全321モジュールの機能網羅・完全互換を主張しません。
- Windows公開版0.2.122-alphaの配布物とmainのアプリ実装は変更しません。Linux版は採用済み0.2.234-alphaを基にした別配布です。

**The attached tar.gz contains the Linux source/runtime Python modules. GitHub's automatic Source code archives refer to the repository baseline, not the complete Linux preview package.** This prerelease does not replace the existing Windows release.

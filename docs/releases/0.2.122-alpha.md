# FluxCAD 0.2.122-alpha — new current-feature public package

2026-10-19 / Windows / FreeCAD 1.1.4

This replaces the old 0.1 preview as the public development baseline. It packages the accepted current 99-module implementation and its required SheetMetal, NetworkX and parser dependencies. It is an alpha, not a statement that all features are complete.

## Included and excluded

Sketch/ellipse/region selection, solid/surface/mesh/drawing tools, plastic features and hollow domes, sheet-metal base/flange/unfold, parameters/CSV, assemblies, interference, render/animation and example working copies are included. Source hashes and LF-only publication normalization are recorded in accepted-runtime.json. The entry macro now prioritizes its own directory to avoid another checkout's modules.

Unaccepted browser.py/fluxcad.py performance edits are excluded; their last accepted versions are used. Machine reconstruction and original/reference CAD, caches, profiles, raw development logs and private settings are not distributed. The small region-selection fixture and UI-produced result are original experiment artifacts, not machine/source data.

**SolidWorks import remains experimental and unfinished.** Display meshes and a restricted native-solid path are shipped as implementations, not certified general compatibility. Configurations, source color fidelity, feature history and arbitrary file correctness are not guaranteed. cadmpeg binary version/hash is verified, but no new SolidWorks conformance test is claimed for this release.

## Validation

- Japanese and English isolated startup/basic operation smoke: 26 checks each. Geometry/hole/parametric edit, Undo/Redo, saved reopen/recompute, 20 existing samples, localized grid palette and offscreen rendering.
- Current-feature native integration: 16 checks per language. Accepted source hashes/module origins, current ribbon, bundled SheetMetal and NetworkX, all eleven new example full recomputes, eight example catalog targets, all six crossing/nested cell extrusions with saved recompute and nonzero tiny-area formatting.
- Actual Japanese physical UI on the new full checkout: reused the physically drawn 16-line fixture; upper cell click, E, six-cell list, 12 mm / 1.440 mm3 extrusion confirmation, toolbar Undo/Redo and Save passed. See physical-ui.json. Selection was not supplied through API.
- Early hidden smoke harness runs exited before writing a report because hiding the last Qt window quit the application. The test fixture now keeps the application alive until checks finish; those early attempts are not passes.

These are scoped checks. They do not certify every command/combination, all selection failures, arbitrary SolidWorks imports or all complex sheet-metal work. Some addon dialogs remain English. Back up working documents and use separate copies.

Final publication-copy check: 17 English native integration checks passed after LF normalization and license metadata on sample copies, including reopening the physical UI extrusion as a valid 1.44 mm3 solid. See final-package-en.json.

## Distribution

Windows ZIP includes the pinned unmodified cadmpeg 0.6.1 executable, libraries' licenses/notices, application sources and examples; it does not bundle FreeCAD. Source ZIP excludes that executable. For native SolidWorks experiments from source, obtain the Windows ZIP's vendor/cadmpeg executable or the exact upstream v0.6.1 binary and verify vendor/cadmpeg/SOURCE.json. Standard tools and display-mesh import do not need this executable.

Build: `python scripts/build_release.py --cadmpeg <existing-pinned-cadmpeg.exe>`. Both ZIPs contain per-file SHA256 manifests. SHA256SUMS.txt covers the download assets.

Attribution: current accepted helper implementations were locally generated/reviewed in the development workflow; the entrypoint helper proposal is preserved under code-provenance. Third-party code is separately attributed in THIRD_PARTY_NOTICES.md. Example-publication.json records license metadata changes on copies while preserving all geometry payload bytes.

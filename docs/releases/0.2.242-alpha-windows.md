# FullArcCAD 0.2.242-alpha — Windows版

旧FluxCADの名称をFullArcCADへ変更した最新Windows x86_64開発版です。旧0.2.122への差分パッチではなく、採用済み343モジュールを基にした完全な配布パッケージです。左上ロゴもFullArcCADです。

## ダウンロードと起動 / Download and launch

- `FullArcCAD-0.2.242-windows.zip` — モジュール・起動スクリプト・アドオン・既存公開サンプル・固定版Windows変換器とライセンス・検証記録
- `FullArcCAD-0.2.242-source.zip` — 同じ実装ソース（decoder等のexe/dll/pydを除外）
- `FullArcCAD-0.2.242-SHA256SUMS.txt` — 2配布物のSHA256

1. Windows用FreeCADを別途用意してください。今回のパッケージ試験はFreeCAD1.1.4です。本体・そのPython・フォントは同梱しません。
2. Windows ZIPを新しい書き込み可能なフォルダーに展開します。旧版への上書きは避けてください。
3. `Start-FullArcCAD.cmd`を実行します。

```powershell
.\Start-FullArcCAD.ps1 -FreeCADPath "C:\Program Files\FreeCAD 1.1\bin\FreeCAD.exe"
```

## 制限 / Limits

開発中のアルファ版で、全機能保証ではありません。SolidWorks厳密BRep変換は実験的です。Windows ZIPに既存固定版cadmpeg.exeとworker・ライセンスを含めましたが、今回新しいユーザーSolidWorksファイルでは試験していません。ソースZIPはdecoderバイナリを含まないため、この機能が必要ならWindows ZIPを使用してください。通常STEP取込とは別の制限です。
